# SBIE2218

**Message:** SBIE2218 Failed to get elevated privileges: _[xx / yyyyyyyy]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックス内で実行されているプログラムによって発行された特権昇格操作を Sandboxie が正常に完了するのを妨げる何らかのエラーが発生しました。特権昇格操作は次のいずれかです:

*   サンドボックス内の一部のサービスを開始する要求、または
*   Windows Vista 以降での、ユーザー アカウント制御 (UAC) を使用して管理者特権に昇格する要求。

このメッセージの後に [SBIE2219](SBIE2219.md) のメッセージが続きます。

**解決策:** このエラーはプログラムのインストール中に発生する可能性があります。考えられる回避策は、管理者特権でインストールを実行することです: 右クリック コマンド Run Sandboxed を使用して Sandboxie の下でインストール セットアップ プログラムを起動し、Run Sandboxed ダイアログ ボックスで Run as UAC Administrator オプションを必ず選択してください。
