# SBIE3209


**Message:** SBIE3209 Cannot find the executable for the default mail agent

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie Start.exe プログラムは、次のレジストリ キーの下に含まれる情報を参照して、Web ブラウザー実行可能プログラム ファイルの場所を特定しようとします:
```
    HKEY_CLASSES_ROOT\mailto
```

そして実際の情報は、次のいずれかのレジストリ キーから取得されます:
```
    HKEY_CLASSES_ROOT\mailto\shell\opennew\command
    HKEY_CLASSES_ROOT\mailto\shell\open\command
```

このエラー メッセージは、必要な情報をレジストリから抽出できなかったことを示します。

**解決策:**

メール プログラムに自身をシステムの既定のメール プログラムとしてリセットさせることで、この問題を修正できる場合があります。プログラムによってこの機能の提供方法が異なるため、特定のメール プログラムのドキュメントを参照してください。

または、[Sandboxie Control](SandboxieControl.md) の [Add Shortcut Icons](ConfigureMenu.md#windows-shell-integration) 機能を使用して Web ブラウザー プログラムへのショートカットを直接作成することで、この問題を回避することを検討してください。
