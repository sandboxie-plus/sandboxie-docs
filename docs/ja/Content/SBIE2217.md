# SBIE2217

**Message:** SBIE2217 Request to run as Administrator was denied due to dropped rights

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックスで [Drop Rights](RestrictionsSettings.md#drop-rights) 設定が有効になっており、これによりプログラムが管理者アカウント特権で起動するのを妨げています。

このメッセージの後に [SBIE2219](SBIE2219.md) のメッセージが続きます。

**解決策:** Drop Rights 設定をオフにします: [Sandbox Settings > Restrictions > Drop Rights](RestrictionsSettings.md#drop-rights)
