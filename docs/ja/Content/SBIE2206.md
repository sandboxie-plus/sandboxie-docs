# SBIE2206

**Message:** SBIE2206 Failed processing AutoExec setting _yy__[[ntstatus](NtStatusCodes.md)]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

[Sandboxie Ini](SandboxieIni.md) 構成ファイルの [AutoExec](AutoExec.md) 設定の 1 つの処理中にエラーが発生しました。

このメッセージは、AutoExec 設定で指定されたプログラムまたはコマンドの実行の結果として発生するエラーに_は_特に関係しないことに注意してください。

このメッセージは、AutoExec 設定に関連する_簿記_が何らかの形で失敗したことを示します。
