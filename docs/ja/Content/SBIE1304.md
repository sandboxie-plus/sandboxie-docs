# SBIE1304

**OBSOLETE**

**Message:** SBIE1304 Blocked simulated keyboard or mouse input by process _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

この警告メッセージは、サンドボックス化されたプログラムが、別のサンドボックス内またはサンドボックス外で実行されているウィンドウに受信されるはずの、シミュレートされたキーボードまたはマウス操作を行ったときに表示されました。その結果、キーボードまたはマウス操作は破棄されました。

この保護の目的は、サンドボックス内で実行されている悪意のあるプログラムが、Windows Explorer などの Sandboxie 外のプログラムと通信することで Sandboxie を回避するシナリオをブロックすることでした。悪意のあるプログラムは、Windows Explorer にサンドボックス内へ移動して悪意のあるプログラムを起動させるキーボード操作をシミュレートできました。

**ゲームと全画面アプリケーション:**

このメッセージは、ゲームまたはアプリケーションの起動中に発行されることがありました。その場合、このメッセージは悪意のあるアクティビティの兆候ではなく、メッセージ SBIE1304 を非表示にするか、この保護を無効にしても安全でした。

関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Restrictions > Hardware Access](RestrictionsSettings.md#hardware-access-removed)

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [BlockFakeInput](BlockFakeInput.md)
