# SBIE1103

**Message:** SBIE1103 Sandboxie driver (SbieDrv) version _x.yy_ failed to start

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは、何らかのエラーまたは非互換性のために初期化を完了できませんでした。このメッセージは失敗の原因を特定しません。失敗の原因を特定するには、メッセージ SBIE1103 より前に記録された他の SBIExxxx メッセージがないかイベント ログを調べてください。
