# Use SbieDesk Hack

`UseSbieDeskHack` はサポートされている Sandboxie 互換性設定のままですが、その現在の動作は Sandboxie の Desktop および Window Station アーキテクチャとともに文書化されています。

[Sandbox Desktop and Window Station を参照](SandboxDesktop.md)。

この設定は既定で有効で、個々の実行可能イメージに対しても構成できます:

```ini
UseSbieDeskHack=n
UseSbieDeskHack=program.exe,n
```
