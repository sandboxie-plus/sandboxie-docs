# SBIE1314

**Message:** SBIE1314 Blocked request to alter network/firewall settings by process _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは、プログラムが TCP/IP ネットワーク構成を変更しようとし、要求がブロックされたことを示します。Sandboxie は、プログラムがローカル コンピューターの IP アドレスまたはルーティング テーブル、あるいはその他のネットワーク パラメーターを変更しようとするのをブロックしたときにこのメッセージを発行することがあります。

現時点では、このメッセージはプログラムがファイアウォール パラメーターを変更しようとしたときには実際には発行されませんが、プログラムはファイアウォールのパラメーターを変更できません。

プログラムがネットワークおよびファイアウォール パラメーターを変更できるようにするには、次の設定を参照してください:

~~関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Restrictions > Hardware Access](RestrictionsSettings.md#hardware-access-removed)~~

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [BlockNetParam](BlockNetParam.md)
