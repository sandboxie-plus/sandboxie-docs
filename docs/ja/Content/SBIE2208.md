# SBIE2208


**Message:** SBIE2208 Cannot remove registry hive: _[[ntstatus](NtStatusCodes.md)]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

すべてのサンドボックス化されたプログラムが終了すると、Sandboxie はサンドボックス化されたレジストリをシステムから削除します。このエラー メッセージは、削除が成功しなかったことを示します。

通常、_ntstatus_ コードは C0000121 で、他のプログラムが_サンドボックス外から_サンドボックス化されたレジストリを使用していることを示します。

レジストリがシステムに読み込まれたままである限り、サンドボックスを削除できないことに注意してください。現在のユーザー アカウントをログオフすると問題が解決する場合があります。
