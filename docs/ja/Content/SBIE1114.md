# SBIE1114

**Message:** SBIE1114 Cannot find Zw system service, reason _xx_

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。このメッセージは、ドライバーが何らかのシステム プロシージャを見つけられなかったことを示します。

このメッセージの後に、関連するプロシージャ名を指定する [SBIE1108](SBIE1108.md) のメッセージが続きます。

**注:** 理由コード **36** は、Windows 組み込みの [Driver Verifier](https://docs.microsoft.com/en-us/windows-hardware/drivers/devtest/driver-verifier) が Sandboxie ドライバー **SbieDrv** に対して有効になっている場合、64 ビット Windows で表示されることがあります。
