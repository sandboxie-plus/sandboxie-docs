# SBIE2220


**Message:** SBIE2220 To permit use of Administrator privileges, please double-click on this message line

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは [SBIE2217](SBIE2217.md) のメッセージに続き、サンドボックスで Drop Rights 設定を有効にする簡単な方法を提供します。

関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Restrictions > Drop Rights](RestrictionsSettings.md#drop-rights)

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [DropAdminRights](DropAdminRights.md)
