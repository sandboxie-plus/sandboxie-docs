# Box Alias

_BoxAlias_ は [Sandboxie Ini](SandboxieIni.md) のサンドボックスごとの設定で、サンドボックスに代替表示名を割り当てます。バージョン 1.14.6 以降で使用可能です。

## 構文

```ini
[MyTestBox]
BoxAlias=Development & Testing
```

エイリアスには、実際のサンドボックス名では無効な表示テキストや特殊文字を含めることができます。

## 表示名とサンドボックス ID

エイリアスは表示専用です。実際のサンドボックス名は INI セクション名であり、サンドボックスの運用上の ID であり続けます。エイリアスの設定は次を名前変更または変更しません:

* `Sandboxie.ini` セクション。
* サンドボックスのファイルまたはレジストリ ルート ID。
* IPC またはその他の内部サンドボックス ID。
* API またはコマンド ライン ツールで使用される名前。
* 強制ルールによって参照されるサンドボックス名。

異なる表示サーフェスは名前を異なる形式にすることがあります。SandMan は通常、実際のサンドボックス名を表示するときにアンダースコアをスペースに置き換えますが、Start.exe および下位レベルのコンシューマーは生の名前を表示することがあります。

## BoxAliasDisplayMode

_BoxAliasDisplayMode_ はバージョン 1.18.2 以降で使用可能なグローバル表示設定です:

```ini
[GlobalSettings]
BoxAliasDisplayMode=0
```

| 値 | 表示動作 |
| --- | --- |
| `0` | エイリアスがアクティブな場合はそれを表示し、それ以外の場合はサンドボックス名を表示します。 |
| `1` | 実際のサンドボックス名を表示します。 |
| `2` | 通常の非コンパクト表示では、空でないエイリアスが実際の名前と異なる場合に `Alias (RealBoxName)` を表示します。コンパクト表示ではエイリアスのみを表示することがあります。 |

この設定は、SandMan、Start.exe、サンドボックス化されたウィンドウ タイトル、境界線、ツールチップ、復元ログ、およびメッセージを含む、いくつかの現在の表示パスによって使用されます。すべてのインターフェイスで同一の書式を保証するものではなく、運用上のサンドボックス識別子を変更しません。

!!! note

    現在のコンポーネントは、_BoxAliasDisplayMode_ が存在しない場合にすべて同じフォールバックを使用するわけではありません。SandMan のメイン表示と境界線のパスはモード `2` を使用し、Start.exe とサンドボックス化されたウィンドウ タイトルの処理はモード `0` を使用します。コンシューマー間で明示的に一貫したモードにするには、_BoxAliasDisplayMode_ を直接構成してください。

    SandMan の Settings インターフェイスは現在、**Sandbox alias and name** を `2` を書き込むのではなく明示的なキーを削除することで保存します。これは現在の UI の動作であり、コンポーネント固有のキー不在フォールバックを有効なままにします。

## グローバル インターフェイス設定

グローバル コントロールは次にあります:

**Global Settings > Interface Config > User Interface > Interface Options**

**Sandbox name display:** セレクターは次を提供します:

| 選択肢 | 保存される値 |
| --- | --- |
| **Sandbox name** | `1` |
| **Sandbox alias** | `0` |
| **Sandbox alias and name** | `2`。現在の SandMan インターフェイスを通じて保存するとキー不在として表現されます |

このセレクターはグローバル表示動作を制御します。エイリアス テキスト自体はサンドボックスごとの設定のままです。

## エイリアスの非表示と復元

現在の SandMan の **Rename Sandbox** ダイアログには、実際のサンドボックス名とそのエイリアスのための別個のコントロールがあります。値を _BoxAlias_ と _BoxAliasDisabled_ の間で移動することで、テキストを破棄せずにエイリアスを非表示にできます:

* アクティブなエイリアスがある場合、_BoxAlias_ がテキストを保存し、_BoxAliasDisabled_ は存在しません。
* **Hide alias** が選択されている場合、_BoxAlias_ が削除され、_BoxAliasDisabled_ がテキストを保存します。
* エイリアスをクリアすると、両方の設定が削除されます。
* 保存されたエイリアスを再度有効にすると、アクティブな _BoxAlias_ 設定に復元されます。

たとえば、非表示のエイリアスは次のように保存されることがあります:

```ini
[MyTestBox]
BoxAliasDisabled=Development & Testing
```

_BoxAliasDisabled_ は非表示のエイリアス用の UI 永続化であり、別のアクティブなエイリアスではありません。通常の表示パスは _BoxAlias_ を読み取ります。エイリアスを非表示にしても _BoxAliasDisplayMode_ は変更されません。

## バージョン履歴

* _BoxAlias_ のメタデータはバージョン 1.14.6 を記載しています。
* _BoxAliasDisabled_ のメタデータはバージョン 1.17.2 を記載しています。Sandboxie Plus 1.17.2 / Classic 5.72.2 のリリース ノートは、作り直された SandMan の名前変更ダイアログとその **Hide alias** の永続化について説明しています。
* _BoxAliasDisplayMode_ のメタデータはバージョン 1.18.2 を記載しています。Sandboxie Plus 1.18.2 / Classic 5.73.2 のリリース ノートは、現在の表示専用の名前サーフェス全体でのその使用について説明しています。
