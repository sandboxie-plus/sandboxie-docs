# SBIE2312


**Message:** SBIE2312 Could not enable BrowseNewProcess setting: _[yy / [ntstatus](NtStatusCodes.md)]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、Internet Explorer プログラムの複数のインスタンスが単一のインスタンスに統合されるのを防ぐようにサンドボックスをカスタマイズしようとしました。このメッセージは、エラーによりカスタマイズが失敗したことを示します。
