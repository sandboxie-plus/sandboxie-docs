# SBIE1242

**OBSOLETE SINCE 0.9.0 / 5.51.0**

**Message:** SBIE1242 Monitor buffer overflow

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

有効にすると、Sandboxie の [Resource Access Monitor](ResourceAccessMonitor.md) コンポーネントは、サンドボックス化されたプログラムによる一部のシステム リソースへのすべてのアクセス試行を記録します。リソースの名前と種類は「モニター バッファー」に保存されます。モニター バッファーは 64KB のメモリのみを使用します。

モニター バッファーが小さいため、同時に保持できるアクセス試行の数は限られています。このエラーは、Resource Access Monitor がモニター バッファーで処理できる数を超えるリソース アクセス試行を検出したことを示します。

実質的に、これは一部のリソース アクセスが Resource Access Monitor によって表示されないことを意味します。これが重要である場合とそうでない場合があります。

考えられる解決策は、サンドボックス化されたプログラムの優先度レベルを下げるか、マルチプロセッサ システムの場合は 1 つのプロセッサのみに制限することです。理想的には、これによりプログラムが一度に実行できるリソース アクセスの数が減ります。
