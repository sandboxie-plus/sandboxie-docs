# SBIE2111


**Message:** SBIE2111 Process is not accessible: _program_, call _call_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

これは情報メッセージです。

v1.0.16 / 5.55.16 より前は、Sandboxie はサンドボックス化されたプログラムが現在のユーザーに属するサンドボックス化されていない任意のプログラムのメモリを読み取ることを許可していました。これは、感染防止だけでなくデータ保護も目標とする場合には明らかに悪い考えです。したがって、v1.0.16 / 5.55.16 以降、Sandboxie はサンドボックス化されていないプロセスまたは他のサンドボックスに属するプロセスに対する _PROCESS_VM_READ_ を許可しません。
互換性を促進するために、このビルドでは [ReadIpcPath](ReadIpcPath.md) サンドボックス設定が導入されています。

関連する Sandboxie Plus 設定: Sandbox Options > General Options > Restrictions > Other restrictions > Issue message 2111 when a process access is denied

参照: [Notify Process Access Denied](NotifyProcessAccessDenied.md)
