# SbieIni コマンド ライン

SbieIni.exe は、Sandboxie 構成を検査および変更するための小さなコマンド ライン ユーティリティです。クエリは現在ドライバーが保持している構成を読み取ります。通常の更新はサービスを通じて [Sandboxie.ini](SandboxieIni.md) を編集し、その再読み込みを試みます。`/drv` は別の高度な直接ドライバー更新ルートです。

## クイック スタート

```batch
SbieIni.exe queryex DefaultBox RecoverFolder
SbieIni.exe set DefaultBox RecoverFolder "C:\Recovery"
```

**バッチ ファイル**からリテラルな Sandboxie 変数 `%Desktop%` を格納するには、パーセント記号を 2 つにします。

```batch
SbieIni.exe set DefaultBox RecoverFolder "%%Desktop%%"
```

CMD は SbieIni.exe が受け取る前に独自の `%VAR%` 式を展開します。上記のパーセント 2 つの例は、特にバッチ ファイル構文です。

## 概要

SbieIni.exe は 3 つの異なるワークフローをサポートしています。

- ドライバー常駐構成のクエリ（読み取り専用）。
- サービスを通じた永続構成の更新（`set`、`append`、`insert`、`delete`）と、それに続く保存およびドライバー再読み込みの試行。
- `/drv` によるドライバー常駐構成の直接更新。通常の INI 保存や再読み込みは行いません。

## 呼び出しの概要

基本形式:

```batch
SbieIni.exe query    [/expand] [/boxes] <section> [setting]
SbieIni.exe queryex  [/expand] [/boxes] <section> [setting]

SbieIni.exe set [/passwd:********] <section> <setting> [value]
SbieIni.exe append|insert|delete [/passwd:********] <section> <setting> <value>
```

注:

- `queryex` は `query /expand` の省略形です。
- `/boxes` はセクション一覧を、実行中のプロセスを持つボックスではなく、現在のユーザーが利用できる有効なサンドボックスにフィルターします。
- `/passwd:` は通常の更新用の構成パスワードを指定します。空のオプション値は対話型プロンプトを開きます。
- 値を省略した `set` は通常の永続削除にのみ使用します。`append`、`insert`、`delete` には空でない値が必要です。
- `/drv` は承認、永続性、削除の制限が異なる高度な更新オプションです。以下を参照してください。

## 構成のクエリ（読み取り専用）

クエリは物理的な INI ファイルではなく、ドライバーの常駐構成を検査します。そのため、出力はファイルと異なる場合があり、ドライバーのみの変更後も同様です。

値クエリはテンプレート由来の値を除外しますが、`GlobalSettings` からの一致する直接値へのフォールバックは保持します。繰り返し設定の場合、要求されたセクション内の直接値の後に、直接グローバル値が続くことがあります。出力は完全な有効構成ではなく、名前付きセクション内の直接値に必ずしも限定されません。

セクションを一覧表示する方法:

```batch
SbieIni.exe query *
```

これは `GlobalSettings` を明示的に出力し、次に常駐構成内のテンプレート由来でない適格なセクションを列挙します。サンドボックスのみの一覧ではありません。現在のユーザーが利用できる有効なサンドボックスのみを一覧表示するには:

```batch
SbieIni.exe query /boxes *
```

ボックスが表示されるために実行中のサンドボックス化されたプロセスは必要ありません。

セクション内の設定を一覧表示する方法:

```batch
SbieIni.exe query DefaultBox *
```

これは、テンプレート除外ルックアップの下でそのセクションに直接表現されている個別の設定名を一覧表示します。グローバル フォールバック名は列挙しません。グローバルに構成された値は、その設定名がこの一覧に存在しなくてもクエリ可能な場合があります。設定を省略した場合も設定名が一覧表示されます。

設定の値を取得する方法:

```batch
SbieIni.exe query DefaultBox RecoverFolder
```

変数をパスに展開する方法:

```batch
SbieIni.exe queryex DefaultBox RecoverFolder
```

`queryex` と `query /expand` は、単に CLI プロセスの環境ではなく、Sandboxie の構成展開コンテキストを使用します。展開された出力は次に NT から DOS へのパス変換の試行を受けますが、すべての文字列が DOS ファイルシステム パスになるわけではありません。展開はテンプレート除外やグローバル フォールバックを変更しません。

構文的に受け入れられたクエリでは、終了コード `0` は値が見つかったことを証明しません。空の出力は、存在しないこと、列挙の終わり、または下位レベルのクエリ、展開、バッファ処理の失敗を意味する場合があります。

## 更新操作（set / append / insert / delete）

`/drv` なしでは、これらのコマンドはサービスの書き込み可能な INI モデルを編集し、Sandboxie.ini の保存を試み、ドライバーの構成の再読み込みを試みます。これは通常の永続ワークフローであり、アトミックなトランザクションではありません。保存または再読み込みが失敗する可能性があり、CLI はその終了ステータスを通じてすべての失敗を確実に報告するわけではありません。

これらの操作は、継承されたテンプレートのソース定義ではなく、名前付きセクションを編集します。実行中のプロセスが変更を認識するかどうかは、各設定のコンシューマーとライフサイクルによって異なります。

### Set — 設定の既存の行を置き換える（または値を指定しない場合は削除する）

```batch
SbieIni.exe set <section> <setting> [value]
```

`set` は設定の既存のエントリを削除し、置換を書き込みます。値を省略すると、代わりに設定が削除されます。空の引用符付きトークン（`""`）も CLI パーサーによって省略された値として扱われます。

通常の永続ルートを通じて構成セクション全体を削除するには:

```batch
SbieIni.exe set BoxName * ""
```

これは細心の注意を払って使用してください。サンドボックスの保存内容ではなく、セクションの構成を削除します。この削除形式は `/drv` と共に使用しないでください。

### Append — 既存のエントリの後に新しい値の行を追加する

```batch
SbieIni.exe append <section> <setting> <value>
```

新しい値は、同じ設定の既存のエントリの後に追加されます。設定が存在しない場合はセクションに追加されます。重複する値は許可されます。これは必ずしもセクションまたはファイルの末尾に追加されるわけではありません。

### Insert — 既存のエントリの前に新しい値の行を追加する

```batch
SbieIni.exe insert <section> <setting> <value>
```

通常の `insert` は、その設定の既存のエントリの前に値を追加します。`/drv` では、`insert` は現在、代わりに追加のセマンティクスを持ちます。

### Delete — 一致する値の行を削除する

```batch
SbieIni.exe delete <section> <setting> <value>
```

これは、完全な値が指定された値と大文字と小文字を区別せずに一致する設定のすべてのエントリを削除します。ワイルドカードは使用しません。設定が存在しないか、一致する値がない場合、削除は書き込み可能モデルでは何も行いません。

### パスワードの処理

通常の更新では、`/passwd:secret` または `/passwd=secret` が構成パスワードを指定します。`/passwd`、`/passwd:`、または `/passwd=` は対話型プロンプトを開きます。Escape キーを押すと更新を発行する前にキャンセルされますが、それでも終了コード `0` を返します。無人自動化に対話型プロンプトを使用しないでください。

## 詳細および自動化の注意事項

### 直接ドライバー更新（`/drv`）

`/drv` は通常の永続更新ルートではありません。通常のサービス側 INI 編集、ファイル保存、または構成再読み込みなしで、ドライバー常駐構成を直接変更します。

ドライバーはサンドボックス化された呼び出し元を拒否し、SbieSvc 自体、またはドライバーが登録されたセッション リーダーとして認識するプロセスからの要求を受け入れます。承認は呼び出し元プロセスの PID をチェックします。リーダー エージェントを実行したり、そこから SbieIni.exe を起動したりするだけでは、SbieIni.exe にその ID が付与されません。SbieIni.exe は自身をセッション リーダーとして登録しません。`/passwd` は `/drv` を承認しません。直接ドライバー API は構成パスワードを受け取らず、管理者昇格だけでは不十分です。

ドライバーのみの変更は Sandboxie.ini に書き込まれず、再読み込みやドライバー ライフサイクルの変更をまたいで永続的な構成として依存してはなりません。すべての変更が存続する、またはすべての変更がすべての再読み込みで消えると仮定しないでください。

現在の制限:

- `/drv insert` は通常の `insert` とは異なり、追加のセマンティクスを持ちます。
- `/drv` を値なしの `set` 削除形式（`""` を含む）と共に使用しないでください。設定またはセクションの削除には通常の永続ルートを使用してください。
- 承認された呼び出し元では、`/drv set <section> * <value>` は、空でない値が続く場合でもドライバー常駐セクション全体を削除します。これは Sandboxie.ini からセクションを削除しません。

### 終了コードと検証

CLI 自体の処理は次の終了コードを使用します。

| コード | 意味と制限 |
| --- | --- |
| `1` | 構文または使用法のエラー。 |
| `2` | 更新が誤った構成パスワードを報告しました。 |
| `0` | 成功の証明ではありません。受け入れられたクエリ、パスワード プロンプトのキャンセル、およびその他の多くの更新失敗がこのコードを返す場合があります。 |

プロセスの開始または読み込みの失敗は、この処理の外で発生する可能性があります。更新を検証するために `ERRORLEVEL 0` だけに依存しないでください。通常の `query` はその後ドライバーのルックアップを確認できますが、その読み戻しはディスク永続性を独立して証明しません。逆に、物理的な INI を検査しても、完全な有効な実行時構成を確立しません。

### CMD 解析と同時編集

- スペースを含む値は二重引用符で囲みます。
- バッチ ファイルでは、クイック スタートに示すように、リテラルな Sandboxie 変数を渡すためにパーセント記号を 2 つにします。
- `""` は、別個の空文字列引数ではなく、省略された位置値になります。
- 引用符の削除後、`/` で始まるトークンは位置値ではなくオプションとして扱われます。引用符で囲むだけでは、そのようなトークンを設定値として使用可能にしません。
- 競合するファイル ロックや同時ライターが永続性を妨げる可能性があります。スクリプトによる更新と同時に INI を編集しないでください。

## 例

```batch
SbieIni.exe query * | sort > Sections.txt
SbieIni.exe query DefaultBox RecoverFolder
SbieIni.exe queryex DefaultBox RecoverFolder
SbieIni.exe append DefaultBox Template RoboForm
SbieIni.exe set DefaultBox AutoRecover n
SbieIni.exe delete DefaultBox RecoverFolder "C:\Old\Path"
```

## 実装と参照

権威ある動作は CLI とそのアクティブなコンシューマーによって定義されます。Sandboxie ソース リポジトリの主要な実装ポイント:

- `apps/ini/cmd.c` — 引数解析ヘルパー。
- `apps/ini/query.c` — クエリ実装と SBIEDLL クエリ ヘルパー。
- `apps/ini/update.c` — 更新動詞、`/passwd` プロンプト、`/drv` と DLL パス。
- `apps/ini/main.c` — プログラム エントリと使用法の処理。
- `core/dll/callsvc.c` / `core/dll/sbieapi.c` — サービス更新ヘルパーとドライバー API ラッパー。
- `core/svc/sbieiniserver.cpp` — 通常の構成編集、保存、および再読み込みの処理。
- `core/drv/conf.c` — 常駐構成クエリと直接ドライバー更新。
