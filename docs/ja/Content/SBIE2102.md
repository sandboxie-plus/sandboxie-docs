# SBIE2102

**Message:** SBIE2102 File is too large to copy into sandbox - _path_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

これは情報メッセージです。

操作が通常のファイル移行を通じて既存のホスト ファイルを変更する必要がある場合、Sandboxie はまずサンドボックス コピーを必要とし、ホスト ファイルが変更されないようにします。

小さなファイルのコピーは一般に大きなファイルのコピーよりもコストが低くなります。大きなファイルの移行は、目立つ時間がかかり、追加のサンドボックス ストレージを消費する可能性があります。

たとえば、コンテンツ移行を通じて 4 GB の DVD バックアップを変更すると、その大きなファイルをサンドボックスにコピーする必要がある場合があります。通常の読み取り専用アクセスは通常、そのようなコピーを必要としません。移行の時間とストレージのコストは、ファイルとストレージ環境によって異なります。

SBIE2102 は、通常のコンテンツ移行サイズの決定が有限の [CopyLimitKb](CopyLimitKb.md) しきい値に達するか超え、明示的な移行ルールがすでに別のモードを選択しておらず、使用可能な移行プロンプト応答が返されない場合のフォールバック通知です。これは [CopyLimitSilent](CopyLimitSilent.md) が有効になっていない場合にのみ発行されます。これは、プロンプトが無効になっている場合、または対話型要求が利用できないかタイムアウトした場合に発生する可能性があります。

一致する明示的な移行ルールは、このサイズ メッセージ パスをバイパスします。肯定的な[大きなファイルのプロンプト](PromptForFileMigration.md)応答は移行を選択します。明示的な **No** 応答は、この決定パスから SBIE2102 なしで非コピーを選択します。_CopyLimitSilent=y_ は SBIE2102 を抑制しますが、移行の決定を変更したり、プロンプトを無効にしたりしません。

承認されていない、移行に依存する最初のオープンの場合、[CopyBlockDenyWrite](CopyBlockDenyWrite.md) は、書き込みおよび削除アクセスを削除した後に、アクセス拒否とするか、ホスト ファイルに対する再試行とするかを制御します。再試行は失敗する可能性があり、このメッセージはファイルが読み取り可能または読み取り専用になることを保証しません。移行を選択しても、コピーが成功することは保証されません。

サイズしきい値とアラート メッセージは、[Sandbox Settings > File Migration](FileMigrationSettings.md) で構成できます。

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [CopyLimitKb](CopyLimitKb.md)、[CopyLimitSilent](CopyLimitSilent.md)、[PromptForFileMigration](PromptForFileMigration.md)、[CopyBlockDenyWrite](CopyBlockDenyWrite.md)
