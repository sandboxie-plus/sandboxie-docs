# SBIE1111

**Message:** SBIE1111 System DLL _name_ could not be loaded _[[ntstatus](NtStatusCodes.md) / yy]_

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。このメッセージは、ドライバーが指定されたシステム DLL を読み込めなかったことを示します。

このメッセージの後に [SBIE1103](SBIE1103.md) のメッセージが続きます。
