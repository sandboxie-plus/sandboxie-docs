# SBIE2316


**Message:** SBIE2316 Memory corrupted

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックス化されたプログラム内で Sandboxie が維持するメモリ領域が破損しました。これは、Sandboxie のエラーにより自身のメモリが破損したためか、サンドボックス化されたプログラムのエラーにより Sandboxie が所有するメモリ領域が破損したためである可能性があります。

サンドボックス化されたプログラムは直ちに中止されます。

サンドボックス化されたプログラムが Sandboxie を回避しようとしてこれらのメモリ領域を破損することはできないことに注意してください。Sandboxie はドライバー コンポーネントを通じて制限を実施し、これはサンドボックス化されたプログラムによって何らかの形で損傷または変更されることはありません。
