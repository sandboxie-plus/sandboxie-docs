# Windows 8

バージョン 4.02 以降、Sandboxie は 32 ビット版と 64 ビット版の両方で、条件なしに Windows 8 を完全にサポートします。

[Download Sandboxie](https://github.com/sandboxie-plus/Sandboxie/releases) Web ページにアクセスしてください。

* * *

バージョン 3.76 以前では、Windows は Sandboxie v3 が Windows 8 と互換性がないと警告します。この警告は 3.72 より前のバージョンの Sandboxie に適用されます。Sandboxie バージョン 3.74 以降を使用する場合、Windows 8 からの警告メッセージを安全に無視できます。
