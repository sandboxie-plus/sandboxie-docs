# SBIE1401

**Message:** SBIE1401 Configuration file not found, using defaults

**ログ記録先:** [System Event Log](SystemEventLog.md) と [Popup Message Log](PopupMessageLog.md)

**説明:**

これは、Sandboxie が [Sandboxie Ini](SandboxieIni.md) 構成ファイルを見つけられず、既定の設定を使用することを示す通知メッセージです。

Sandboxie は、[Sandboxie Ini](SandboxieIni.md) ファイルを最初に Windows ディレクトリ (通常は C:\Windows) で探し、そこに見つからない場合は Sandboxie インストール フォルダーで探します。
