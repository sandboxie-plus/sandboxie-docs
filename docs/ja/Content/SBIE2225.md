# SBIE2225

**Message** SBIE2225 An attempt was made to access an EFS file: %2

**Severity**: Warning

## 説明

このメッセージは、Sandboxie がサンドボックス化されたプロセスが Windows Encrypting File System (EFS) で保護されたファイルにアクセスしようとしたことを検出し、その試みがブロックされたかプロキシできなかったときにログに記録されます。

メッセージには、試行されたファイル アクセスのパスが含まれます。多くの場合、これはサンドボックス化されたプロセスに EFS アクセスを許可するのを妨げる構成または証明書の問題を示します。

## 一般的な原因

- ボックスに対してサンドボックス設定 EnableEFS が有効になっていない。
- 暗号化機能を備えた高度なサポーター証明書が存在しないか、アクティブでない。
- 試行されたパスが EFS プロキシの対象でない (たとえば、サポートされているデバイス パス上に存在しない)。
- UserServer コンポーネントでのアクセス許可、マッチング、またはハンドル複製エラーによりプロキシ操作が失敗した。

## Sandboxie が行うこと

- ファイルのオープン/作成操作中に EFS で保護されたファイルを検出します。
- EnableEFS が構成されており、サポーター証明書に暗号化機能が含まれている場合、Sandboxie は要求を UserServer サービスにプロキシし、サンドボックス化されたプロセスにハンドルを複製して戻すことにより、ファイル操作を実行しようとします。
- プロキシが失敗した場合、または EnableEFS が許可されていない場合、Sandboxie は SBIE2225 をログに記録し、サンドボックス化されたプロセスのファイルへのアクセスを拒否します。

## 推奨される操作

1. サンドボックスの [Sandboxie.Ini](SandboxieIni.md) のボックス セクション、または Sandboxie 設定 UI を介して、そのサンドボックスが EnableEFS=y を持っていることを確認します。[^1]
2. 高度なサポーター証明書がインストールされてアクティブであり、暗号化オプション (opt_enc) が含まれていることを確認します。[^2]
3. ターゲット パスがサポートされているデバイス (通常は \Device\HarddiskVolume*) 上にあることを確認します。[^3]
4. EFS アクセスが機能することを期待しているのに機能しない場合は、ドライバー/ファイルのトレースを有効にしてログを収集し、プロキシの失敗の診断に役立ててください (TraceLog および EnableEFS のドキュメントを参照)。[^4]

## 関連するメッセージと設定

- [SBIE6004](SBIE6004.md) — サポーター証明書が存在しないか不十分です。[^2]
- [EnableEFS](EnableEFS.md) — 上記で再利用された拡張説明、例、および追加の脚注が含まれています。
- [TraceLog](SandboxieTrace.md) - Sandboxie の監視下で実行されているプログラムによってアクセスされるすべてのシステム リソースの名前を表示します。

## 実装上の注意と脚注

以下の注意は Sandboxie ソース内の実装ポイントを参照しています。これらは、SBIE2225 がどのように生成されるかを追跡したいメンテナーおよび上級ユーザーを対象としています。

[^1]: EnableEFS は [EnableEFS](EnableEFS.md) で説明されているボックス レベルの設定です。有効にすると、Sandboxie はサンドボックス化されたプロセスの EFS プロキシを許可します。

[^2]: 証明書チェックは、プロキシ操作を試みるときに UserServer パスで実行されます。コードは EFS プロキシを許可する前に CertInfo.active と CertInfo.opt_enc の両方を検証します。証明書チェックが失敗するとプロキシ要求が拒否され、SBIE6004 または SBIE2225 がログに記録される可能性があります。

[^3]: UserServer は、\Device\HarddiskVolume (ハード ディスク ボリューム) で始まるパスにプロキシ操作を制限します。これらのデバイス パス外の要求は EFS プロキシの対象ではありません。

[^4]: SBIE2225 は、EFS アクセス要求を処理しようとしているときに File_NtCreateFileProxy() または関連するプロキシ コードが失敗したときにログに記録されます。エラーはプロキシ パス内の SbieApi_Log(2225, TruePath) によって出力されます。
