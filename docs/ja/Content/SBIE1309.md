# SBIE1309

**Message:** SBIE1309 Denied attempt to change account password

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、サンドボックス化されたプログラムがユーザー アカウントのパスワードを変更しようとしたことを検出し、要求を拒否しました。

~~関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Restrictions > Low-Level Access](RestrictionsSettings.md#low-level-access-removed)~~

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [BlockPassword](BlockPassword.md)
