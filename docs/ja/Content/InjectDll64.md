# Inject Dll 64

_InjectDll64_ は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定で、x64 SbieDll パスを使用して対象となるサンドボックス化されたプロセスの起動中に追加の DLL を読み込みます。「インジェクト」とはそのプロセスに DLL を読み込むことを意味し、すべてのサンドボックス化されたプログラムへの読み込みを保証するものではありません。例:

```ini
   .
   .
   .
   [DefaultBox]
   InjectDll64=c:\Program Files\Sandboxie Utilities\Sample64.dll
```

DLL への完全なパスを指定する必要があります。DLL ファイル自体がサンドボックス内にある場合、サンドボックス内の完全なパスを指定します。DLL はアクセス可能でターゲット プロセスと互換性がある必要がありますが、ファイルのアクセス許可とイメージ マッピング制限によって依然として読み込みが妨げられることがあります。

**注:** 適用される SbieDll ビルドが設定を選択し、Windows のビット数だけが選択するわけではありません。ネイティブ x64 は `InjectDll64` を使用します。x86 プロセスは 64 ビット Windows 上でも [InjectDll](InjectDll.md) を使用します。ネイティブ ARM64 は `InjectDll64` ではなく `InjectDllARM64` を使用します。ARM64 上の x64 用の Sandboxie の ARM64EC 固有ビルドは、現在のソース/ビルド モデルでは `InjectDll64` を使用します。これは任意の ARM64EC DLL との独立したランタイム テスト済みの互換性ではありません。

メイン ページで説明されている同じ読み込み、オプション コールバック、失敗、および再起動の制限が適用されます。構成の再読み込みは、既に初期化されたプロセスでこれらの DLL を自動的に読み込んだりアンロードしたりしません。

参照: 包括的な説明については [InjectDll](InjectDll.md)。
