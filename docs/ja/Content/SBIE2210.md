# SBIE2210


**Message:** SBIE2210 Cannot start Windows Explorer for: _folder__(xxxx)_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、サンドボックス化されたプログラムがフォルダーを「探索」するよう要求したときに Windows Explorer (プログラム _explorer.exe_) を起動しようとします。

このメッセージは、メッセージに記載された _folder_ を探索するために Windows Explorer プログラムを起動できなかったことを示します。
