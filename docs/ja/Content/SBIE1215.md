# SBIE1215

**OBSOLETE**

**Message:** SBIE1215 Cannot resolve path to process image _[xxxxxxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

何らかのエラーにより、Sandboxie はサンドボックス内で起動されたプログラムへの完全なパスを特定できませんでした。Sandboxie は、プログラムがサンドボックス内にインストールされているか外にインストールされているかを特定するために完全なパスを必要とします。この区別は、[OpenFilePath](OpenFilePath.md) ([OpenPipePath](OpenPipePath.md) と比較してください)、[ClosedFilePath](ClosedFilePath.md)、[ClosedKeyPath](ClosedKeyPath.md)、および [ClosedIpcPath](ClosedIpcPath.md) などの設定に影響します。
