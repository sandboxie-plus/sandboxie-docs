# SBIE1211

**Message:** SBIE1211 Could not initiate sandboxing for process _name_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックス内でプログラムが起動するたびに、Sandboxie はプログラムがサンドボックス内で正常に実行されるように準備する一連の初期化手順を完了する必要があります。このメッセージは、これらの手順の 1 つ以上が失敗したことを示します。

これは要約メッセージであり、エラーの正確な原因を示す 1 つ以上の他のエラー メッセージの後に続きます。
