# ボックスの表示とアクション

`BoxIcon`、`CustomColor`、`DblClickAction`、および `PinToTray` は、ボックスごとの SandMan 表示および対話設定です。これらは構成サーフェスを共有しますが、目的は異なります。アイコンの表示、プリセット変更中の色の保持、ダブルクリック アクション、およびトレイ リストのフィルタリングです。これらはサンドボックス分離の制御ではなく、ボックスの色やアイコンはそのセキュリティ プリセットの証明ではありません。

現在の SandMan コンシューマーは、これらの値をサンドボックス セクションから直接読み取ります。`GlobalSettings` フォールバック、有効なテンプレート継承、または展開された実効ポリシー ルックアップを要求せず、これらの設定に対してプロセス/イメージまたは ProcessGroup セレクターをサポートしません。テンプレートまたは `GlobalSettings` にのみ存在する値はここでは使用されません。値をサンドボックス セクションにコピーするワークフローは、これらのコンシューマーが使用できる直接値を作成します。この制限は一般的な Sandboxie の構成システムには適用されません。

現在の Sandboxie Control Classic コードには、これら 4 つの設定名に対する専用のコンシューマーまたは同等のコントロールがありません。INI ファイルにそれらが存在しても、同じ Classic UI 動作は提供されません。

## カスタム ボックス アイコン

`BoxIcon` は Windows アイコン リソースを `path,index` として指定できます。

```ini
[ExampleBox]
BoxIcon=C:\Windows\System32\shell32.dll,0
```

あるいは、絶対イメージ パスを手動で構成します。

```ini
[ExampleBox]
BoxIcon=C:\Icons\box.png
```

直接イメージは Qt のイメージ処理を使用します。サポートされる形式は、ビルドで利用可能なイメージ サポートに依存します。`BoxIcon` は、SandMan のメイン サンドボックス リスト/ツリー、Run Sandboxed ボックス ピッカー、Sandbox Options プレビュー、およびシステムトレイのボックス リスト/メニューで、関連するアイコン表示設定に従って使用されます。

カスタム アイコン、色生成アイコン、ボックス タイプ アイコン、およびステータス オーバーレイは、別個の表示レイヤーです。カスタム アイコンを読み込めない場合、フォールバック動作はサーフェスによって異なります。トレイは、通常の色/タイプ アイコンを使用する前に、非組み込み `DblClickAction` のターゲット アイコンを試すことができます。メイン サンドボックス ツリーは同じフォールバックを使用しません。アイコンの選択は、ボックス タイプ、セキュリティ プリセット、または実行時の強制を変更しません。

**Sandbox Options > General Options > Box Options > Appearance** で、カラー ボタンのメニューを開き、**Custom icon** を選択します。アイコン ピッカーは Windows リソースの選択を `path,index` として保存します。専用のイメージ パス エディターではありません。色のリセット コントロールは色をリセットし、`BoxIcon` はリセットしません。

## カスタム色の保持

```ini
[ExampleBox]
CustomColor=y
```

`CustomColor` は色を定義しません。実際の色は [`BorderColor`](BorderColor.md) に残ります。`CustomColor=y` は、**Box Type Preset** を変更するときにその色を保持するよう SandMan に指示します。フラグがない場合、プリセットを変更すると新しく選択されたプリセットの色が適用されることがあります。カスタム `BorderColor` はこのフラグなしでも使用できます。フラグはプリセット変更中の保持に関するものです。

この設定は境界線を有効にしたり、RGB 値を含んだり、境界線の幅や不透明度を制御したりしません。また、以前のセキュリティ/分離プリセットも保持しません。色が保持されている場合でも、**Box Type Preset** を変更すると適用可能なプリセット コントロールが変わります。

`CustomColor` というラベルのチェックボックスはありません。**Sandbox Options > General Options > Box Options > Appearance** の色コントロールがその状態を管理します。カスタム色を選択または調整すると、適用時に `CustomColor=y` が記録されます。プリセット色にリセットすると、適用時にフラグが削除されます。直接値がない場合、コンシューマーのフォールバックは無効になります。

## ダブルクリック アクション

`DblClickAction` は、サンドボックス上で適用可能なダブルクリックのアクションを選択します。

```ini
[ExampleBox]
DblClickAction=!browse
```

**Sandbox Options > General Options > Box Options > Double click action:** で、編集可能なセレクターは次を提供します。

| 値 | SandMan ラベル | アクション |
| --- | --- | --- |
| `!options` | **Open Box Options** | Sandbox Options を開きます。 |
| `!browse` | **Browse Content** | SandMan のサンドボックス コンテンツ ブラウザーを開きます。 |
| `!recovery` | **Start File Recovery** | ファイル復元ウィンドウを開いてスキャンします。即時復元は有効になりません。 |
| `!run` | **Show Run Dialog** | `Start.exe` を通じて Run Sandboxed ダイアログを開きます。 |

値が存在しないか空の場合は Sandbox Options を開きます。**Open Box Options** を選択すると、通常は `!options` を保存するのではなく `DblClickAction` を削除します。`!` で始まる不明な値も Sandbox Options を開きます。**Ctrl + ダブルクリック**は、構成されたアクションに関係なく Sandbox Options を開きます。

`!` で始まらない空でない値は、そのサンドボックスのために `Start.exe` に転送されるコマンド テキストです。例:

```ini
[ExampleBox]
DblClickAction="C:\Tools\example.exe" --example
```

これは [`RunCommand`](RunCommand.md) 名、Run Menu キャプション、またはプログラム エイリアスではありません。ディスパッチャーはそれを Run Menu エントリに対して解決せず、現在のセレクターはそれらのエントリを自動的に一覧表示しません。無制限のシェル言語パーサーではないため、パイプラインやリダイレクトが解釈されると仮定しないでください。

無効なカスタム コマンド テキストでも、Sandbox Options への自動フォールバックではなく、起動の試行が発生します。下流の起動エラーが発生する可能性があり、失敗時に構成された値が自動的に削除されることはありません。インターフェイスでアクションを変更すると、カスタム アイコンの選択も更新される場合があります。変更を適用する前に確認してください。

## ボックスをトレイに固定する

```ini
[ExampleBox]
PinToTray=y
```

`PinToTray` は、SandMan のトレイ リスト フィルターに対してボックスを固定としてマークします。直接値がない場合、そのコンシューマーとチェックボックスは未固定にフォールバックします。サンドボックスのために別個の通知領域アイコンを作成するものではありません。

チェックボックスは **Sandbox Options > General Options > Box Options** にあり、**Always show this sandbox in the systray list (Pinned)** とラベル付けされています。チェックすると直接 `PinToTray=y` が書き込まれ、チェックを外すと通常は直接スカラー値が削除されます。継承されたテンプレート/グローバル値は表示されません。

SandMan の設定 `Options/SysTrayFilter` は **Global Settings > Shell Integration > System Tray > Show boxes in tray list:** で構成されます。これはマネージャー設定であり、これらのボックス コンシューマーによって継承される `GlobalSettings` 値ではありません。その値が存在しない場合のフォールバックは **All Boxes** です。

| トレイ モード | 非アクティブ、未固定 | アクティブ、未固定 | 固定 |
| --- | --- | --- | --- |
| All Boxes | 表示 | 表示 | 表示 |
| Active + Pinned | 非表示 | 表示 | 表示 |
| Pinned Only | 非表示 | 非表示 | 表示 |

これは、ボックスがそれ以外の点で有効かつ利用可能であることを前提としています。固定しても、無効または利用できないボックスがトレイ リストに強制されるわけではありません。チェックボックスの「Always」という表現は、それらの条件をバイパスしません。

## 変更の適用

SandMan で変更を適用するか、外部で編集した後に構成を再読み込みします。これらの設定はサンドボックス化されたアプリケーションの再起動を必要としません。

- 変更された `BoxIcon` 値は、SandMan が関連する表示サーフェスを再読み込み/再構築するときに表示される場合があります。読み込まれたアイコンはキャッシュされます。構成されたパス/文字列を変更せずに外部アイコン ファイルを置き換えると、古いアイコンが表示されたままになる場合があります。SandMan を再起動すると、そのアイコン キャッシュが強制的に再構築されます。
- `CustomColor` または他の設定の外部変更後は、Sandbox Options を再度開いて、そのコントロールが新しい直接値を反映するようにします。色の保持は、そのインターフェイスでプリセットを変更するときに適用されます。
- `DblClickAction` は、適用可能なサンドボックスのダブルクリックごとに読み取られます。構成を適用/再読み込みした後の次のジェスチャーで新しいアクションを使用できます。アイコンのキャッシュはアクションのディスパッチとは別個です。
- `PinToTray` は、トレイ リスト/メニューが再構築されるときに評価されます。変更を適用/再読み込みした後に再度開きます。固定に SandMan の再起動は通常必要ありません。
