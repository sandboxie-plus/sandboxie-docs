# SBIE1405


**Message:** SBIE1405 Configuration file error in line _number_: syntax error

**ログ記録先:** [System Event Log](SystemEventLog.md) と [Popup Message Log](PopupMessageLog.md)

**説明:**

[Sandboxie Ini](SandboxieIni.md) 構成ファイルは、一連のセクションとして構成されています。各セクションは、たとえば [GlobalSettings] のように、角括弧で囲まれたセクション名で始まります。

各セクション内では、各行は _name=value_ の形式でなければなりません。

または、構成ファイル内の行は空であるか、シャープ記号 (#) で始まる場合があり、その場合その行はコメントと見なされ無視されます。

このメッセージは、構成ファイル内の一部のテキストが上記の構文に従って解析できなかったことを示します。
