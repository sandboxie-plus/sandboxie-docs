# SBIE2213

**Message:** SBIE2213 Windows Credentials cannot be stored in the sandbox

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:** Windows 資格情報 API を使用すると、アプリケーションはユーザー名、パスワード、および関連するサインイン情報を保存および取得できます。Sandboxie のユーザー モード資格情報互換性レイヤーは、資格情報操作のために [Protected Storage](ProtectedStorage.md) (PStore) バッキング実装を初期化できないときにこのメッセージをログに記録します。初期化パスは ERROR_NO_SUCH_LOGON_SESSION を設定し、失敗を返します。そのバックエンドを必要とする傍受された資格情報操作はしたがって失敗する可能性があり、結果は操作によって異なります。このメッセージは、すべての資格情報が破棄されたことを確立するものではありません。

WinCred フックの範囲とネイティブ読み取りスルー動作については [Open Credentials](OpenCredentials.md) を、これらの互換性フックをバイパスする別個のテンプレートについては [Open Protected Storage](OpenProtectedStorage.md) を参照してください。
