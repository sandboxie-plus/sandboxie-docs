# SBIE2205

**Message:** SBIE2205 Service not implemented: _name_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:** Sandboxie は、メッセージに記載された操作が互換性コンポーネントの 1 つによって実装されていない場合に、この一般的な診断を使用します。これは資格情報や [Protected Storage](ProtectedStorage.md) に固有のものではありません。サンドボックス化されたアプリケーションは、その操作が必要かどうかに応じて続行または失敗する場合があります。

Sandboxie の互換性実装は、すべてのシステム操作を再現するわけではありません。PStore 実装では、IPStore::GetTypeInfo が確認されているサポート外のメソッドの 1 つです。これはその名前とともに SBIE2205 をログに記録し、失敗を返します。メッセージに表示される名前は、何がサポート外であったかを識別します。このメッセージだけから、資格情報情報がサンドボックスから漏えいしたこと、または CredReadA などの特定の WinCred 操作が本質的に未実装であると推測しないでください。

関連する動作については、[Protected Storage](ProtectedStorage.md)、[Open Protected Storage](OpenProtectedStorage.md)、および [Open Credentials](OpenCredentials.md) を参照してください。
