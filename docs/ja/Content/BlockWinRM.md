# Block WinRM

*BlockWinRM* は、Windows Remote Management (WinRM) とそのリモート コマンド コンポーネントである WinRS に対する Sandboxie の緩和策です。ホストの WinRM サービスを無効にしたり、すべてのネットワークをブロックしたりするものではありません。現在の Sandboxie は、ファイル コンポーネントの制限と、サンドボックス化されたレジストリ ビュー内の別個のポリシー値を適用します。

## 現在の適用レイヤー

`[DefaultTemplates]` 内の必須の `Template_BlockWinRM` は、関連する Windows システム ディレクトリ配下の WinRM/WinRS コンポーネント `wsmsvc.dll`、`wsmauto.dll`、および `winrs.exe` に対して `ClosedFilePath` ルールを提供します。これらはサンドボックス化されたプロセスのファイル アクセス制限であり、考えられるすべてのリモート管理経路がブロックされることを保証するものではありません。

別途、サンドボックスの初期カスタマイズ中に、有効な `BlockWinRM` オプションによって、Sandboxie は次の場所に DWORD `AllowNegotiate=0` を書き込もうとします:

```text
HKLM\Software\Policies\Microsoft\Windows\WinRM\Client
```

この値はサンドボックス化されたレジストリ ビューに配置されます。Sandboxie はこの操作を通じてホストの実際の WinRM ポリシーを変更しません。

## 構成と `n` の意味

```ini
[DefaultBox]
BlockWinRM=y
```

有効な値が存在しない場合、この設定は既定で `y` になります。ボックス固有の値は `[GlobalSettings]` よりも優先されます。このオプション専用の SandMan または Sandboxie Control Classic のチェックボックスはありません。SandMan では、**Sandbox Options > Edit ini Section > Edit ini** を使用してブール値を手動で構成します。

現在の実装では、`BlockWinRM=n` は、カスタマイズがまだ実行されていない場合に、ブール値で制御される `AllowNegotiate=0` カスタマイズを防ぎます。それ自体では、必須の `Template_BlockWinRM` によって提供されるファイル制限を削除し _ません_。他の該当するファイル アクセス ルールが、それらのコンポーネントへの有効なアクセスを引き続き決定します。したがって、`n` はサンドボックス内で WinRM を完全に有効にする一般的なスイッチではありません。

過去の Sandboxie Plus 0.7.1 / Classic 5.48.5 の変更履歴には、`BlockWinRM=n` が WinRM ファイル ブロックを無効にすると記載されていました。それは以前の直接ドライバー パスを説明したものであり、現在のビルドではそれらのファイル ルールに既定のテンプレートを使用します。

## 変更の適用

ファイル コンポーネント ルールは、プロセスの開始時にそのファイル ポリシーに読み込まれます。関連するファイル ルールを変更した後は、影響を受けるサンドボックス化されたプロセスを再起動してください。

レジストリ カスタマイズは異なります。これはボックスが最初にカスタマイズされるときに実行され、サンドボックス コンテンツに状態を残します。後で `BlockWinRM` を変更しても、既存の `AllowNegotiate=0` 値が自動的にクリアされたり、既存のボックスに対してカスタマイズが必ず再実行されたりするわけではありません。変更が初期のサンドボックス ポリシー状態に影響する必要がある場合は、空のボックスまたは新しく作成したボックスを使用し、そのプロセスを再起動してください。ボックスを空にすると既存のサンドボックス コンテンツが削除されるため、必要なものは先に保存してください。

## スコープと関連ページ

この設定は、ネットワーク共有のファイルおよびフォルダーへのアクセスを制御する [Block Network Files](BlockNetworkFiles.md) とは異なります。どちらの設定も、インターネット アクセスまたはファイアウォール ポリシーを置き換えるものではありません。手動構成については [Sandboxie Ini](SandboxieIni.md) を参照してください。

## バージョン履歴

`BlockWinRM` は Sandboxie Plus 0.7.1 / Classic 5.48.5 で追加されたとリストされています。必須の `[DefaultTemplates]` は 0.9.8 / 5.53.0 で登場しました。1.7.3 / 5.62.3 で、WinRM ファイル コンポーネント ルールは `Template_BlockWinRM` に移動され、`[DefaultTemplates]` に含まれました。以前のブール値で制御されるドライバー ファイル リストは、もはやアクティブなパスではありません。
