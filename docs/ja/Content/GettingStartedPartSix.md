# はじめに 第 6 部

### 第 6 部: まとめ

このチュートリアルでは、Sandboxie を使用および理解するための基本原則を説明しました。
```
  * Sandboxie を使用してアプリケーションを実行する方法
  * 変更がどのようにサンドボックス内に閉じ込められるか
  * 重要なファイルやドキュメントをサンドボックスから復元する方法
  * サンドボックスを削除する方法
```

Sandboxie の使用に関するその他のヒントは、[使用のヒント](UsageTips.md)ページ、および特定の Web ブラウザーに関するページ（[Internet Explorer のヒント](InternetExplorerTips.md)、[Firefox のヒント](FirefoxTips.md)）で読むことができます。

Sandboxie を使用する際に覚えておくべき重要な点は、Sandboxie がプログラムを互いに分離するように設計されていることです。したがって、プログラム間の相互運用性が_多少_失われることを覚悟しておく必要があります。たとえば:

*   電子メール: 電子メール（_mailto_）リンクをクリックすると、通常は Web ブラウザーが電子メール ソフトウェアを起動します。Sandboxie がそのサンドボックスで電子メール ソフトウェアを実行するように構成されていない限り、これは正しく機能しません。[FAQ メール](FAQEmail.md)を参照してください。



*   この問題は、電子メール リンクを左クリック（通常のクリック）する代わりに右クリックすることで回避できます。右クリック メニューで電子メール アドレスを**コピー**できます。次に電子メール ソフトウェアに切り替えて、電子メール アドレスを**貼り付け**ます。貼り付けた電子メール アドレスが **mailto:** プレフィックスで始まる場合は、コロン (:) を含めてそのプレフィックスを必ず**削除**してください。



*   ダウンロード マネージャー: ダウンロード リンクをクリックすると、Web ブラウザーの外部で動作するソフトウェアによって傍受および処理されます。Web ブラウザーがサンドボックス内で実行されていると、ダウンロード マネージャーもサンドボックス内で起動される可能性があり、おそらく望ましくない結果になります。



*   この問題は、ダウンロード リンクを左クリック（通常のクリック）する代わりに右クリックすることで回避できます。右クリック メニューでリンクを**コピー**できます。次にダウンロード マネージャー プログラムに切り替えて、リンクを**貼り付け**てダウンロード プロセスを開始します。



一方で、プログラム間の相互運用性が_すべて_失われることを覚悟する必要はありません。たとえば、キーストロークやマウス クリックに反応してポップアップ ウィンドウに情報を表示する辞書ソフトウェアを使用する場合があります。辞書ソフトウェアの設計によっては、Sandboxie がこれに干渉する場合としない場合があります。期待どおりに動作しない場合は、Sandboxie のサポートで報告し、解決策を求めてください。

* * *

また、[サンドボックス設定](SandboxSettings.md)ウィンドウの多くの設定を確認する時間を取ってください。設定は明確に説明されており、セキュリティと利便性の最適なバランスを見つけるための多くの設定があります。

たとえば、Web ブックマークやお気に入りに対するセキュリティと制御をより重視し、まずサンドボックスに保存してから、[クイック復元](QuickRecovery.md)または[即時復元](ImmediateRecovery.md)を通じて選択した項目を復元することを好む人もいるでしょう。（これが Sandboxie の既定の構成です。）

しかし、サンドボックス化された Web ブラウザーが、中間の復元手順なしでブックマークやお気に入りに直接アクセスできるように Sandboxie を構成することを好む人もいるでしょう。その場合は、セキュリティをいくらか犠牲にして利便性を高めることになります。

Sandboxie では、セキュリティと利便性の個人的なバランスを見つけることができます。

楽しんでください!
