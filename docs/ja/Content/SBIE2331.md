# SBIE2331


**Message:** SBIE2331 Service start failed: _[yy / xxxx] text_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

[Sandboxie Control](SandboxieControl.md) は、Sandboxie サービス コンポーネント (SbieSvc) が実行されていないことを検出しました。次に Sandboxie Control はサービスを開始しようとしましたが、失敗しました。このメッセージは、サービスの開始を妨げるエラー コードを指定します。

たとえば、詳細が _[22 / 5] Access is denied_ の場合、サービス SbieSvc が実行されておらず、[Sandboxie Control](SandboxieControl.md) がサービスを開始する権限を持たないユーザー アカウントで実行されていることを示します。
