# BoxGrouping

`BoxGrouping` は Sandboxie Plus 1.9.1 以降で利用可能なユーザー設定値です。SandMan がサンドボックスを視覚的なグループに整理するために使用するユーザーごとの階層を保存します。

ボックス グループはユーザー インターフェイスのメタデータにすぎません。サンドボックスの分離や内容を変更せず、同じグループ内のサンドボックスが設定を共有することもありません。視覚的なネストは構成の継承や親子サンドボックスを作成しません。

## 保存とスコープ

`BoxGrouping` は [Sandboxie Ini](SandboxieIni.md) に、通常はアクティブな Windows ユーザーのセクションに保存されます。

```ini
[UserSettings_12345678]
BoxGrouping=:Browsers,DefaultBox
BoxGrouping=Browsers:ChromeBox,Private
BoxGrouping=Private:FirefoxBox
```

これはサンドボックスごとの設定ではなく、`[GlobalSettings]` の下に保存されず、テンプレート継承を使用しません。各 Windows ユーザーは通常、別個の `[UserSettings_xxxxxxxx]` セクションを持ち、したがって異なる階層を持つ場合があります。ポータブル構成は代わりに `[UserSettings_Portable]` を使用する場合があります。

## 構文

一般的な形式は次のとおりです。

```ini
BoxGrouping=<parent>:<member1>,<member2>,...
```

例:

```ini
BoxGrouping=:Box1,Group1
BoxGrouping=Group1:Box2,SubGroup
BoxGrouping=SubGroup:Box3
BoxGrouping=EmptyGroup:
```

- コロンの前のテキストが親グループです。
- 空の親はルート レベルを表します。
- コロンの後のエントリは親の直接の子です。
- 子は、その名前が独自の `BoxGrouping=<name>:` エントリも持つ場合、サブグループです。
- 同じ親の繰り返し行はそのメンバー リストを拡張します。
- コロンで終わるエントリは空の名前付きグループを定義します。

SandMan はネストされたグループをサポートします。この構成:

```ini
BoxGrouping=:Browsers,DefaultBox
BoxGrouping=Browsers:ChromeBox,Private
BoxGrouping=Private:FirefoxBox
```

は次を表します。

```text
Browsers
├── ChromeBox
└── Private
    └── FirefoxBox

DefaultBox
```

ネストは純粋に組織的なものです。`Private` は設定や制限を `FirefoxBox` に渡しません。

## ルート レベルと階層の正規化

空の親キーはルートを表します。例:

```ini
BoxGrouping=:DefaultBox,Browsers
```

は `DefaultBox` と `Browsers` の両方を最上位に配置します。SandMan はこの宛先を `[None]` として表示する場合があります。`[None]` は実際の名前付きグループではありません。

SandMan は階層をツリー状の構造に正規化し、各項目が 1 つの親を持つことを意図しています。UI はグループをそれ自体またはその子孫に移動することを防ぎます。手動編集によって作成された不正な重複または循環データは自動的に正規化される場合があります。正確な競合解決に依存すべきではありません。

## 順序

`BoxGrouping` は、SandMan の手動順序モードで使用されるメンバー順序を保存します。アルファベット順や列の並べ替えなど、他のアクティブな並べ替えモードは、同じ階層を異なる順序で表示する場合があります。

この順序は表示メタデータです。サンドボックスまたはプログラムの実行順序を制御しません。

## SandMan でのグループの管理

SandMan はメイン サンドボックス ツリーでグループを直接管理します。関連する操作には次が含まれます。

- **Sandbox > Create Box Group**
- ツリーまたはグループのコンテキスト メニューからのグループの作成
- **Move Sandbox** および **Move Group**
- **Move Up** および **Move Down**
- ドラッグ アンド ドロップ

サンドボックスを移動すると、その視覚的な位置と保存された順序のみが変わります。サンドボックス ファイルを移動したり、サンドボックスを再作成したり、そのプロセスを再起動したり、実行時ポリシーを変更したりしません。

### 項目の削除、名前変更、および追加

グループを削除しても、そのサンドボックスは削除されません。**Remove Group** は組織ノードを削除し、その直接のサンドボックスとサブグループを削除されたグループの親レベルに移動します。最上位グループが削除された場合、その内容は最上位項目になります。

SandMan を通じてサンドボックスの名前を変更すると、そのグループ参照が更新されます。グループの名前を変更すると、その内容が保持され、親関係が更新されます。

それ以外に割り当てられていない新しいサンドボックスはルートに表示されます。対象グループが選択された状態で作成またはインポートが行われると、SandMan はそのサンドボックスをそのグループに配置できます。サンドボックスの複製は現在、ソース サンドボックスのグループ メンバーシップを保持します。

## ツリー展開の状態

展開および折りたたまれたツリーの状態は `BoxGrouping` に保存されません。SandMan はそれをユーザー インターフェイス構成として別途保存します。

現在の起動時の動作は **Global Settings > Interface Config > User Interface > Group state on start** で選択でき、モードには次が含まれます。

- **Remember previous state**
- **Expand all groups**
- **Collapse all groups**

要するに、`BoxGrouping` はメンバーシップ、階層、および手動の兄弟順序を保存し、ツリー展開の状態は別個です。

## 実行時または分離への影響なし

`BoxGrouping` は次に影響しません。

- ファイル、レジストリ、またはプロセスの分離
- プログラム開始の制限
- リソース制限またはアクセス ルール
- サンドボックスの内容
- 構成の継承
- 実行順序

各サンドボックスは、表示されるグループに関係なく独立して構成されたままです。視覚的な階層はポリシー階層を意味しません。ボックス グループは、グループ全体の設定、グループ テンプレート、共有制限、または追加の分離を提供しません。

## 手動編集と再読み込みの動作

SandMan は通常 `BoxGrouping` を自動的に管理します。手動編集は可能ですが、不正なグラフは正規化される場合があります。修正された階層が表示される前に、SandMan が構成変更を監視または再読み込みする必要があります。グループ化は UI のみであるため、サンドボックス化されたアプリケーションを再起動する必要はありません。

コロンとコンマは、永続化された形式における構造的な区切り文字です。手動で作成したグループ名に `:` を使用しないでください。またコンマを使用しないでください。SandMan の UI はコンマを含むグループ名を拒否します。UI はグループ名の括弧と制御文字も拒否します。

## Sandboxie Plus と Classic

SandMan は `BoxGrouping` を使用します。Sandboxie Control Classic およびレガシー `Start.exe` ボックス セレクターは `BoxDisplayOrder` を引き続き使用します。

`BoxDisplayOrder` はレガシー レイアウト形式であり、現在の SandMan レイアウトでは `BoxGrouping` によって置き換えられたものとしてマークされています。SandMan は、`BoxGrouping` マッピングが利用できない場合のフォールバックとしてレガシー階層を使用できますが、Plus と Classic は 2 つの形式を継続的に同期しません。Classic は依然として `BoxDisplayOrder` を消費するため、完全に廃止されたと見なすべきではありません。

対応するユーザー インターフェイス ワークフローについては、[Sandbox メニュー](SandboxMenu.md)と [Sandboxie Plus 移行ガイド](PlusMigrationGuide.md)を参照してください。

## エクスポートとバックアップの動作

`BoxGrouping` はユーザー インターフェイス構成であり、エクスポートされたサンドボックスの固有のメタデータではありません。通常のボックスのみのエクスポートとインポートは、ユーザーのグループ化階層をサンドボックスと共に運びません。関連するユーザー設定セクションを含む完全な `Sandboxie.ini` バックアップは、それを保持できます。

## バージョン履歴

現在の `BoxGrouping` 保存形式は、ボックス グループ化構成ストレージの作り直しの一環として Sandboxie Plus 1.9.1 で導入されました。グループ化機能自体はこの設定より前から存在します。以降のバージョンで、ネストされたグループ化、名前変更、ドラッグ アンド ドロップ、トレイ階層、順序、および展開状態の永続化が追加または修正されました。
