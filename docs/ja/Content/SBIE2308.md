# SBIE2308

**Message:** SBIE2308 Could not create object directory: _[yy / xxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

プロセス間通信 (IPC) オブジェクトは、プログラム間のさまざまな形式の通信に使用される論理オブジェクトです。IPC オブジェクトは識別名を持ち、ディレクトリの階層構造に編成されています。

Sandboxie は、サンドボックス内と外のプログラム間の通信の分離を保証するために、サンドボックス化されたプログラムによって作成されたすべての IPC オブジェクトを、階層構造内の分離されたディレクトリにリダイレクトします。

このメッセージは、Sandboxie が分離されたディレクトリの作成に失敗したことを示します。

**ゲストまたは制限付きアカウント**

ゲストまたは制限付きユーザー アカウントで Sandboxie を実行している場合は、そのユーザー アカウントに IPC オブジェクトの作成が許可されていることを確認してください:

*   コントロール パネル > 管理ツール > ローカル セキュリティ ポリシーを開きます
*   セキュリティ設定 > ローカル ポリシー > ユーザー権利の割り当てを展開します
*   「グローバル オブジェクトの作成」という名前のエントリを見つけます
*   そのエントリにゲストまたは制限付きユーザー アカウントが一覧表示されていることを確認します
*   「永続的な共有オブジェクトの作成」という名前のエントリを見つけます
*   そのエントリにゲストまたは制限付きユーザー アカウントが一覧表示されていることを確認します
