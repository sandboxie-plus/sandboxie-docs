# SBIE9302

**Message:** SBIE9302 Section creation failed (device setup classes)

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のサービス コンポーネント (SbieSvc) が、プロセス間共有メモリ セクションに関連する何らかのエラーに遭遇しました。

このメッセージは通常、1 つ以上のプログラムがサンドボックス化して実行されている間に Sandboxie サービスが再起動されたときに発生します。

このメッセージの後に [SBIE9305](SBIE9305.md) のメッセージが続きます。
