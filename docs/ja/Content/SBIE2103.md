# SBIE2103


**Message:** SBIE2103 Denied attempt to load system driver _driver_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

これは情報メッセージです。

Sandboxie の監視下で実行されているプログラムは、ドライバーを起動するために必要な特権が削除されています。~~(これが [Block Drivers](BlockDrivers.md) 設定を通じて明示的に許可されている場合を除きます。)~~

このメッセージは、サンドボックス化されたプログラムがドライバーの起動を要求し、その要求が拒否されたことを示します。

状況によっては、このメッセージは、悪意のある [rootkit](https://en.wikipedia.org/wiki/Rootkit) をシステムにインストールする試みが Sandboxie によって阻止されたことを示す_場合があります_。一方、ドライバーをインストールして有効化することが知られているプログラムのサンドボックス内インストール中にこのメッセージが表示される場合は、前述の記述は当てはまりません。
