# SBIE1116

**Message:** SBIE1116 Driver failed to register process notification routine [_[ntstatus](NtStatusCodes.md)_ / _yy_]

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。このメッセージは、Sandboxie がプロセス (アプリケーション) の開始と停止時に通知を提供するようシステムに要求しましたが、システムがこの要求に対応できなかったことを示します。

技術的には、Sandboxie はプロセス通知ルーチンの登録を要求しており、この要求が失敗しました。

**エラー [C000000D / 11] と [C000009A / 22]**

通常、メッセージはエラー詳細 [C000000D / 11] または [C000009A / 22] とともに発行されます。これは、多数の_他の_セキュリティ製品がそのようなプロセス通知ルーチンをすでに登録していることを示します。システムはこれらのルーチンを限られた数しか登録しません。この場合、いわば Sandboxie のための余地を作るために、_他の_セキュリティ製品をいくつかアンインストールすることで問題が解決する場合があります。

**この問題に関する Microsoft の修正プログラムを参照してください:** [https://support.microsoft.com/kb/2922790](https://support.microsoft.com/kb/2922790)

このメッセージの後に [SBIE1103](SBIE1103.md) のメッセージが続きます。
