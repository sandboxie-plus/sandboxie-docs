# SBIE2309


**Message:** SBIE2309 Could not disable COM+/DCOM: _[yy / [ntstatus](NtStatusCodes.md)]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、サンドボックス内からのコンピューター間 COM 接続 (DCOM) を無効にするようにサンドボックスをカスタマイズしようとしました。このカスタマイズにより、サンドボックス内の COM フレームワーク ([SandboxieRpcSs](ServicePrograms.md#remote-procedure-call-rpc) および [SandboxieDcomLaunch](ServicePrograms.md#dcom-server-process-launcher) を参照) がこのコンピューター間接続を提供できなくなります。このメッセージは、エラーによりカスタマイズが失敗したことを示します。
