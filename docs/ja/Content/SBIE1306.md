# SBIE1306


**Message:** SBIE1306 Sandboxie driver (SbieDrv) cannot be unloaded now

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie ドライバー コンポーネントは使用中であり、現時点ではアンロードできません。

Sandboxie ドライバー コンポーネントは、Sandboxie 固有の「Prepare to Stop」要求が発行されるまで、標準の汎用「Stop Service」要求に応答しないことに注意してください。Sandboxie 固有の要求は、要求が発行された時点でドライバーが他のプログラムによって使用されている場合、失敗することがあります。

Sandboxie 固有の要求が成功すると、ドライバー コンポーネントは自身を無効にし、メモリからアンロードされる前に汎用の「Stop Service」要求を待ちます。

また、ドライバー コンポーネントは、Sandboxie の監視下で実行されているプログラムからの停止要求に応じないことにも注意してください。
