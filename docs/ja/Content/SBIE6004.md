# SBIE6004

**Message** SBIE6004 The configuration %3 of box %2 requires a supporter certificate. Processes in this box will be terminated after 5 minutes. For prolonged use, please consider supporting this project.

**Severity**: Error (popup)

## 説明

このエラーは、Sandboxie がボックス構成にサポーター証明書 (または高度なサポーター証明書) が必要であるが、それが存在しないかアクティブでないことを検出したときに表示されます。メッセージはポップアップとして表示され、影響を受けるボックス内のプロセスは短い猶予期間の後に終了される場合があります。

一般的なシナリオには、分離を弱める機能や、サポーター証明書オプションによってゲートされる特権プロキシ操作 (たとえば EFS プロキシ) を有効にする機能が含まれます。

## 一般的な原因

- サポーター証明書を必要とする機能がボックス構成で有効になっている (たとえば EnableEFS) が、システムに有効なアクティブなサポーター証明書がない。
- インストールされた証明書は存在するが、アクティブとしてマークされていないか、必要なオプション フラグ (たとえば EFS プロキシに使用される暗号化フラグ) が欠けている。
- ドライバー/サービスから照会したときに証明書の検証が失敗した。

## 推奨される操作

1. メッセージに記載されたボックス構成を確認します (%3 は構成名、%2 はボックス名です)。証明書を提供する予定がない場合は、証明書を必要とする機能を無効にします。
2. その機能を使用する予定の場合は、必要なオプション フラグを含むサポーター証明書をインストールしてアクティブにします。
3. 証明書のインストール後に Sandboxie コンポーネント (サービス/ドライバー) を再起動して、ドライバーとサービスが新しい証明書を検出できるようにします。
4. 有効な証明書があるにもかかわらずメッセージが表示され続ける場合は、ログを収集し (トレースを有効にする)、サービス/ドライバーの証明書照会パスにエラーがないか確認します。
