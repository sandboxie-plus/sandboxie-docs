# SBIE2307


**Message:** SBIE2307 Could not map drive _x__[[ntstatus](NtStatusCodes.md)]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

内部的に、Windows は A: や C: などのドライブ文字を認識せず、代わりにデバイスを識別する命名スキームを使用します。たとえば
```
	\Device\Floppy0
	\Device\HarddiskVolume1
```

はそれぞれドライブ A: と C: の内部名である場合があります。

Sandboxie は Windows のこの低レベルで動作し、内部名を使用します。ただし便宜上、ファイルがサンドボックス フォルダーに保存されるときは、_\sandbox\drive\a_ および _\sandbox\drive\c_ として保存されます。

したがって、各ドライブについて、Sandboxie は関連する内部名を知る必要があり、たとえば C: と _\Device\HarddiskVolume1_ の間でマッピングできます。

このメッセージは、Sandboxie がメッセージに記載されたドライブ _x_ の内部名を見つけられなかったことを示します。
