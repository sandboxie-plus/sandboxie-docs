# SBIE2306


**Message:** SBIE2306 Could not locate user directory: _[[ntstatus](NtStatusCodes.md) / yy]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、個人用 (「ユーザー プロファイル」とも呼ばれる) ファイルを特定の名前ではなく汎用的な名前のフォルダーに保存することで、サンドボックスの移植性を高めようとします。

たとえば、ファイルを次に保存する代わりに
```
	\sandbox\drive\c\Users\joe\Documents
```

Sandboxie はファイルを次に保存することを好みます
```
	\sandbox\drive\c\user\current\Documents
```

これは、同じサンドボックスを別のユーザー アカウントまたは別のコンピューターで使用できることを意味します。

このメッセージは、Sandboxie がユーザー プロファイル フォルダーを見つけられず、サンドボックス フォルダー _user\current_ に関連付けるフォルダーがわからないことを示します。
