# SBIE2321


**Message:** SBIE2321 Cannot manage device map: _[[ntstatus](NtStatusCodes.md) / yy]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

デバイス マップは、Windows セッション内のドライブ文字のセットと、それに対応するデバイスです。通常、プログラム (サンドボックス化して実行中かどうかに関係なく) は、実行されているセッションのデバイス マップを自動的に継承します。

ただし、場合によっては、Sandboxie はプログラムをデバイス マップから切り離す方法で起動します。これらの場合、Sandboxie は正しいデバイス マップを復元する試みも行います。このメッセージは、何らかのエラーが発生したためにデバイス マップをサンドボックス化されたプログラムに適用できなかったことを示します。
