# SBIE2108

**Message:** SBIE2108 Faking successful completion for program _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

これは情報メッセージです。

特定の場合において、特定のソフトウェアのサンドボックスへのインストールは、プロセス全体の一部のマイナー コンポーネントで発生するエラー条件のために失敗します。

このメッセージは、Sandboxie がインストールを成功させるために、このマイナー コンポーネントのエラー条件を非表示にしたことを示します。
