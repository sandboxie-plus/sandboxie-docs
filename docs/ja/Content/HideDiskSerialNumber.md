# Hide Disk Serial Number

HideDiskSerialNumber は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定です。

```ini
[DefaultBox]
HideDiskSerialNumber=y
```

有効にすると、Sandboxie はインターセプトされた `GetVolumeInformationByHandleW` パスを通じて返される Windows の **ボリューム シリアル番号** を置き換えます。これは製造元の物理ディスク シリアル番号ではありません。置換値は生成されるか、[Disk Serial Number](DiskSerialNumber.md) によって提供されます。他のディスクおよびボリューム識別 API は異なるパスを使用することがあり、この設定はすべてのディスク識別子や WMI クエリをカバーするものではありません。

Sandboxie は元の Windows 関数を呼び出し、そのブール結果を返します。置換シリアルを提供しても、失敗した元の呼び出しが成功に変わるわけではありません。選択された置換値は、元のボリューム シリアル値に対してサンドボックス化されたプロセス内にキャッシュされます。カスタム値を変更しても、既にキャッシュされたエントリは置き換えられません。

有効な値が構成されていない場合、ランタイム フォールバックは無効です。ブールの照会はプロセス イメージによって修飾でき、該当するテンプレートまたはグローバル構成を含めることができます。Sandboxie は有効化の値を読み取り、プロセスの初期化中にこのフックをインストールするため、変更された有効化の値を適用したり置換キャッシュを再構築したりするには、影響を受けるサンドボックス化されたプロセスを再起動するのが確実な方法です。

**Sandbox Options > Advanced Options > Privacy** で、**Hide Disk Serial Number** はボックスの直接の設定を制御します。継承された有効な値はチェックボックスの状態と異なることがあります。
