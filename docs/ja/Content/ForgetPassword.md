# Forget Password

_ForgetPassword_ は [Sandboxie Ini](SandboxieIni.md) のグローバル設定です。[Sandboxie Control](SandboxieControl.md) または [Sandman](PlusMigrationGuide.md) で設定すると、メイン ウィンドウが非表示になったときに構成パスワードがクリアされ、構成設定を変更するには再入力が必要になります。

使用法:

```
   .
   .
   .
   [GlobalSettings]
   ForgetPassword=y
```

[Configuration Protection](ConfigurationProtection.md) も参照してください。

関連する Sandboxie Plus 設定: Options メニュー > Global Settings > Advanced Config > Sandboxie.ini Presets > Clear password when main window becomes hidden
