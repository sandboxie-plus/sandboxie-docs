# SBIE2310


**Message:** SBIE2310 Name buffer is approaching overflow (_n_)

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは Sandboxie の問題状態を識別します。これは内部エラーの結果であるか、より一般的には、何らかのサードパーティ ソフトウェアとの非互換性が発生しています。

**既知の競合**

このメッセージは通常、**PC-Tools Spyware Doctor V7** との競合の兆候です。
