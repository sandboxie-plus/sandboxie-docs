# SBIE1312

**Message:** SBIE1312 Blocked request to start a 16-bit DOS program in the sandbox

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、そのようなプログラムのサンドボックス分離を保証できないため、サンドボックス内での 16 ビット DOS プログラムの実行をブロックします。

このメッセージは、32 ビット Windows 上の 32 ビット版 Sandboxie でのみ表示されることに注意してください。64 ビット Windows では 16 ビット DOS プログラムは実行されません。

考えられる回避策の 1 つは、DOS エミュレーション ソフトウェア [DOSBox](https://www.dosbox.com) をサンドボックスにインストールし、それを使用して 16 ビット DOS プログラムを実行することです。
