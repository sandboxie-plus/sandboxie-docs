# SBIE2311

**Message:** SBIE2311 Could not disable recycle bin (BitBucket): _[yy / [ntstatus](NtStatusCodes.md)]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、サンドボックス化されたプログラムのためにごみ箱を無効にするようにサンドボックスをカスタマイズしようとしました。代わりに、サンドボックス化されたプログラムはごみ箱を使用せずにファイルとフォルダーを直接削除する必要があります。このメッセージは、エラーによりカスタマイズが失敗したことを示します。
