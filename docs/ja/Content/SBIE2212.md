# SBIE2212


**Message:** SBIE2212 Email reader _program.exe_ is not configured to run sandboxed

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは、メール リーダー プログラムをサンドボックス化して実行しているが、Sandboxie でそのプログラムの適切なサポートをまだ有効にしていない場合に表示されます。

Sandboxie はほとんどの電子メール プログラムの簡単な構成を提供しています。[Sandbox Settings > Applications > Email Reader](ApplicationsSettings.md#email-reader)、次に [Test Email Configuration](TestEmailConfiguration.md) を参照してください。

既定では、Sandboxie はメールボックス ファイルへの変更 (新しいメールの追加など) を含め、サンドボックス内のすべての変更をトラップします。これらの変更は、サンドボックスが削除されると削除されます。メール プログラムをサンドボックス化して正しく実行するには、メールボックス データ ファイルをサンドボックス化から除外するよう Sandboxie を構成する必要があります。詳細については、[Email Protection](EmailProtection.md) を参照してください。
