# Yes Or No Settings

一部の [Sandboxie Ini](SandboxieIni.md) 設定はブール設定です。つまり、何かがそうであるかそうでないかを示し、Yes/No の質問に答えます。

設定が有効 (または選択済み、または yes) であることを示すには、Y を指定します。

設定が無効 (または未選択、または no) であることを示すには、N を指定します。

指定されていない、または Y か N 以外の値を指定したブール設定は、特定の設定に依存する既定値に暗黙的に戻ります。たとえば、[OpenProtectedStorage](OpenProtectedStorage.md) 設定の既定値は N です。
