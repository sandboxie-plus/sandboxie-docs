# Protected Storage

Windows Protected Storage (PStore) は、アプリケーションが `PStoreCreateInstance` および `IPStore` API を通じて、パスワードやその他の機密値など、保護されることを意図したユーザー データを保存できるようにしたレガシ インターフェイスです。[Open Credentials](OpenCredentials.md) で説明されている Windows Credential API (WinCred) とは別個です。これらの機能は、現代の Windows パスワード ストアの交換可能な名前として扱うべきではありません。

通常のサンドボックスでは、Sandboxie は通常 `PStoreCreateInstance` を独自の `IPStoreImpl` 互換実装に置き換えます。そのローカル変更はサンドボックス ローカルのバッキング ストレージを使用します。現在のコードは既定で Windows ディレクトリの下に `SbiePst.dat` ファイル名を構築しますが、ビルド時のファイル名の上書きが可能で、サンドボックスのファイル仮想化が物理的な場所を決定します。固定のホスト パスに依存しないでください。この実装は、レガシ PStore インターフェイスを使用するアプリケーションの互換性を提供するもので、すべての Windows 資格情報メカニズムが分離されているという保証ではありません。

PStore の読み取りは、対応するローカル レコードが存在しない場合、Sandboxie のサービスを通じてネイティブ PStore にも照会でき、列挙はネイティブ プロバイダーからの結果を含むことがあります。したがって、ローカルのバッキング ファイルはサンドボックスのみの読み取りを意味しません。実際の結果はネイティブ プロバイダーの可用性とアクセス チェックに依存します。

Sandboxie の既定の WinCred 互換レイヤーも、傍受された資格情報の変更のためのバッキング ストレージとしてこの PStore 実装を使用します。その読み取りおよび列挙パスは依然としてネイティブ Windows 資格情報ストアに照会できます。この重要な境界については [Open Credentials](OpenCredentials.md) を参照してください。

## データの可視性と保護

Sandboxie の置き換えは、アプリケーションごとのプライベート PStore ファイルではなく、サンドボックス化された Windows パス内の共通のバッキング ファイルを使用します。そのファイルへのアクセスは依然としてサンドボックスとホストのアクセス許可に依存するため、これは Windows ユーザー アカウント間の可視性を確立しません。

現在のファイル形式は、保存されたブロックに単純な可逆変換を適用するもので、強力な暗号化ではありません。PStore 項目を含むサンドボックス データは機密として扱ってください。バッキング ファイルがサンドボックス内に残っている場合、そのサンドボックスの内容を削除するとローカル項目もそれとともに削除されます。これはホストの資格情報や、開かれたホスト パスを通じて保存されたデータを削除しません。

## システム実装を開く

関連するシステム エンドポイントを開くルールを追加するには、[Open Protected Storage](OpenProtectedStorage.md) テンプレートを選択します。保護ストレージ IPC エンドポイントに対する有効な Open ポリシーにより、Sandboxie は置き換えの PStore フックとそのユーザー モード WinCred フックをスキップします。古い `OpenProtectedStorage=y` ブールは現在の方法ではありません。

[Application Compartment](../PlusContent/compartment-mode.md) も Sandboxie の PStore 置き換えフックをスキップします。WinCred フックには別個のチェックがあるため、compartment モードだけを `OpenCredentials` を自動的に有効にするものとして説明すべきではありません。

これらの互換性の選択は、サンドボックス化されたアプリケーションがシークレットを保存またはアクセスする可能性のあるすべての方法をカバーするものではありません。サポートされていない PStore メソッドについては [SBIE2205](SBIE2205.md) を、Sandboxie の資格情報バッキング ストアの初期化失敗については [SBIE2213](SBIE2213.md) を参照してください。
