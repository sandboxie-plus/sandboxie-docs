# 使用のヒント

* [クイック復元](QuickRecovery.md)と[即時復元](ImmediateRecovery.md)について詳しく学びましょう。

* ブラウザー固有のヒント: [Internet Explorer のヒント](InternetExplorerTips.md)と [Firefox のヒント](FirefoxTips.md)。

* より良い[メール保護](EmailProtection.md)のために、メール プログラムをサンドボックス内で実行します。[FAQ メール](FAQEmail.md)も参照してください。

* Sandboxie を使用して[キーロガーを防御する](DetectingKeyLoggers.md#defending-against-key-logger)方法を学びましょう。

* [ショートカット アイコンの追加](ConfigureMenu.md#windows-shell-integration)ボタンを使用して、プログラムをサンドボックス内で実行するショートカットを作成します。

* [ファイル メニュー -> ウィンドウはサンドボックス化されていますか?](FileMenu.md#is-window-sandboxed)コマンドを使用して、サンドボックス化されたウィンドウとプログラムを識別します。

* Web ブラウザーなどの[プログラムを強制実行](ProgramStartSettings.md#forced-programs)して、常にサンドボックス内で実行されるようにします。

	* 「強制実行」プログラムを Sandboxie の監視下ではなく実行する必要がある場合は、[強制プログラムを無効化](FileMenu.md#disable-forced-programs)します。

* [サンドボックス設定 > 強制フォルダー](ProgramStartSettings.md#forced-folders)を使用して、CDROM ドライブと DVD ドライブを保護します。

* 個々のプログラムをより適切に分離するために、[さらにサンドボックスを作成](SandboxMenu.md#create-new-sandbox)します。

> 注: プログラムをサンドボックス内で実行するとは、Sandboxie の監視下でそのプログラムを起動することを意味します。
