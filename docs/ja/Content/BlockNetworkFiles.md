# Block Network Files

*BlockNetworkFiles* は、サンドボックス化されたプロセスからのネットワーク共有上のファイルおよびフォルダーへのアクセスを制御します。ファイアウォールやインターネット接続のブロックではなく、ファイル パスの制限です。

## 構成と既定値

```ini
[DefaultBox]
BlockNetworkFiles=y
```

`y` の場合、一致するファイル アクセス ルールがアクセスを許可しない限り、ネットワーク共有パスは読み取りと書き込みの両方でブロックされた状態から始まります。`n` の場合、通常のサンドボックス ファイル アクセス ルールに従いますが、それでも制限されることがあります。別個のネットワーク ポリシーが、共有に到達するために必要な接続を妨げることもあります。

有効な値が存在しない場合、ドライバーはフォールバックとして `n` を使用しますが、設定メタデータには既定として `y` がリストされています。通常、SandMan または Sandboxie Control Classic によって作成された新しく初期化されたボックスは、明示的に `BlockNetworkFiles=y` を受け取ります。ボックス固有の値は、`[GlobalSettings]` から継承された値よりも優先されます。

## ネットワーク ファイルのスコープと例外

この制限は、通常の UNC 共有やマップされたネットワーク ドライブを含む、認識されたネットワーク リダイレクター パスを介したファイル アクセスを対象とします。SMB パケットやポートをブロックするのではなく、ネットワーク ファイルシステム パスに適用されます。他のプロバイダーを介したアクセスは、Sandboxie が認識するパスおよびその他の該当するルールの対象のままです。

より具体的なファイル アクセス ルールは、選択されたネットワーク パスへのアクセスを許可できます。たとえば、一致する `OpenFilePath` はホスト ファイルへの直接アクセスを許可し、`ReadFilePath` は書き込みなしの読み取りを許可できます。ルール固有性モードでは、`NormalFilePath` が一致したパスの通常のサンドボックス ファイル処理を復元できます。これらのルールでは、サポートされているプログラムまたはプロセス グループのセレクターも使用できます。結果は一致するルールとその優先順位に依存します。オープン ルールが別個のすべてのクローズ ルールを上書きすると想定すべきではありません。

`BlockNetworkFiles` は [Block WinRM](BlockWinRM.md)、インターネット アクセス ルール、または [WFP Support](../PlusContent/WFPSupport.md) を置き換えるものではありません。逆に、`n` に設定しても、別個のネットワークまたはデバイスの制限が適用される場合に共有に到達できることは保証されません。

## ユーザー インターフェイス

SandMan では、**Sandbox Options > Network Options > Other Options > Block network files and folders, unless specifically opened.** を使用します。

詳細オプションでボックスを作成する場合、**Sandbox Isolation options > Network Access > Allow access to network files and folders** は逆の意味になります。チェックすると `BlockNetworkFiles=n` が書き込まれ、チェックを外すと `y` が書き込まれます。ウィザードはこのアクセス チェックボックスを既定でオフにし、強化されたボックスの種類では無効にします。

SandMan は、ネットワーク ファイルのブロックが無効な場合、ボックスの状態に **Net Share** を表示することがあります。状態インジケーターは、有効なファイルおよびネットワーク ルールを確認することの代わりにはなりません。

Sandboxie Control Classic も、その Sandbox Settings インターフェイスでネットワーク ファイルのチェックボックスを提供します。

## 変更の適用

ドライバーは、各サンドボックス化されたプロセスを初期化するときにこのオプションを読み取ります。変更後は影響を受けるサンドボックス化されたプロセスを再起動してください。すでに実行中のプロセスは、変更によって保存された値が再構築されることはありません。新しく開始されたプロセスのために、通常、SandMan、サービス、またはドライバーの再起動は必要ありません。

## バージョン履歴

設定メタデータには導入バージョンが指定されていません。Sandboxie Plus 1.7.1 / Classic 5.62.1 は、`BlockNetworkFiles=y` にもかかわらずマップされたネットワーク ドライブへのアクセスを許していた `RestrictDevices=y` との相互作用を修正しました ([issue #2629](https://github.com/sandboxie-plus/Sandboxie/issues/2629))。
