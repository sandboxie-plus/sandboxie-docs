# SBIE2327


**Message:** SBIE2327 Error in COM server: _[yy / xxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

特定の場合において、Sandboxie はサンドボックス化されたプログラムに代わって通信チャネルとして機能し、サンドボックス外で実行されている COM オブジェクトに特定の要求を転送します。

通信チャネルは、Sandboxie サービス コンポーネント (これも _SbieSvc.exe_ と呼ばれます) によって起動される _SbieSvc.exe_ プログラムとして実装されます。このメッセージは、通信チャネルとして機能するこれらの _SbieSvc.exe_ プログラムの 1 つでエラーが発生したことを報告します。

この通信チャネルは、サンドボックス化されたプログラムが [OpenClsid](OpenClsid.md) 設定に一致する CLSID 識別子を使用して COM オブジェクトに接触しようとしたときに使用されます。

関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Resource Access > COM Access](ResourceAccessSettings.md#com-access)

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [OpenClsid](OpenClsid.md)
