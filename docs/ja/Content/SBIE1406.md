# SBIE1406


**Message:** SBIE1406 Missing or invalid expansion for _variable_: _[xxxxxxxx]_

**ログ記録先:** [System Event Log](SystemEventLog.md) と [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは、構成ファイル内で参照されている変数 (名前はメッセージに記載) をテキスト コンテンツで置き換えられないことを示します。

たとえば、変数 %USERNAME% はユーザー アカウント名に展開 (または置換) されます。Sandboxie がユーザー アカウント名を特定できない場合 (メッセージ [SBIE1408](SBIE1408.md) および [SBIE2209](SBIE2209.md) を参照)、変数 USERNAME を名指ししてメッセージ SBIE1406 が発行されます。

展開可能な変数の一覧については、[Expandable Variables](ExpandableVariables.md) を参照してください。

**テンプレート変数**

メッセージ内の変数名が **Tmpl** で始まる場合は、[Sandbox Settings > Applications > Folders](ApplicationsSettings.md#folders) に移動し、不足している変数に関連付けるフォルダー場所を選択してください。

たとえば、**Tmpl.Eudora** に対してこのエラー メッセージが表示された場合は、_Folders_ 設定ページに移動し、Eudora 用のフォルダーを選択してください。
