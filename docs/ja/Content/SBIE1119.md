# SBIE1119

**Message:** SBIE1119 Cannot create API device [_[ntstatus](NtStatusCodes.md)_]

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。このメッセージは、Sandboxie を制御するために使用される内部の論理デバイス オブジェクトを作成できなかったときに発行されます。

このメッセージの後に [SBIE1103](SBIE1103.md) のメッセージが続きます。
