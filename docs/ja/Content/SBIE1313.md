# SBIE1313

**OBSOLETE**

**Message:** SBIE1313 Blocked direct disk access by process _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは、プログラムがハード ディスク デバイスへの直接アクセスを要求し、Sandboxie がこのアクセスを拒否したことを示していました。Sandboxie の既定の動作は、このメッセージを発行せずにすべての直接アクセス要求を拒否することに注意してください。メッセージは、[NotifyDirectDiskAccess](NotifyDirectDiskAccess.md) 設定がすでに有効になっている場合にのみ発行されました。詳細については [NotifyDirectDiskAccess](NotifyDirectDiskAccess.md) を参照してください。
