# SBIE2211


**Message:** SBIE2211 Sandboxed service failed to start: _name_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックスにインストールされた Windows サービスは Sandboxie によって管理されます。この管理には、サービスの開始と停止が含まれます。このメッセージは、サンドボックス化されたサービス _name_ の起動に失敗したことを報告します。

**ユーザー アカウント制御**

Windows Vista 以降では、インストールを実行する前に [Run As UAC Administrator](FileMenu.md#run-as-uac-administrator) オプションを有効にしない限り、ソフトウェアがサンドボックスに正しくインストールされない場合があります。

特に、Windows Installer サービスを通じてインストールされる Windows Installer パッケージでは、このオプションを有効にする必要があります。これはセキュリティ上の問題ではありません。「Run As UAC Administrator」オプションは、Sandboxie の保護をいかなる形でも低下させません。
