# SBIE1101

**Message:** SBIE1101 Sandboxie driver (SbieDrv) version _x.yy_ initialized

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントが正常に初期化されました。このメッセージは通常、システム起動シーケンスのある時点で、ドライバー コンポーネントが起動した後にログに記録されます。Sandboxie のインストールが成功した後にもログに記録され、その際にドライバーが起動または再起動されます。
