# SBIE3208

**Message:** SBIE3208 Cannot find the executable for the default Web browser

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie Start.exe プログラムは、次のレジストリ キーの下に含まれる情報を参照して、Web ブラウザー実行可能プログラム ファイルの場所を特定しようとします:
```
    HKEY_CLASSES_ROOT\.html
```

通常、そのレジストリ キーは、次のレジストリ キーにあるさらなる情報を指します:
```
    HKEY_CLASSES_ROOT\htmlfile
```

そして実際の情報は、次のいずれかのレジストリ キーから取得されます:
```
    HKEY_CLASSES_ROOT\htmlfile\shell\opennew\command
    HKEY_CLASSES_ROOT\htmlfile\shell\open\command
```

このエラー メッセージは、必要な情報をレジストリから抽出できなかったことを示します。

**解決策:**

Web ブラウザーに自身をシステムの既定の Web ブラウザーとしてリセットさせることで、この問題を修正できる場合があります。ブラウザーによってこの機能の提供方法が異なるため、特定の Web ブラウザーのドキュメントを参照してください。

または、[Sandboxie Control](SandboxieControl.md) の [Add Shortcut Icons](ConfigureMenu.md#windows-shell-integration) 機能を使用して Web ブラウザー プログラムへのショートカットを直接作成することで、この問題を回避することを検討してください。
