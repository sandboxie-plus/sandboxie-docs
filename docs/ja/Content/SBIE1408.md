# SBIE1408

**Message:** SBIE1408 Unknown user name for SID: _S-1-5-x-y-z_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、セキュリティ S-1-5-x-y-z をユーザー アカウント名に変換する必要があります。このメッセージは、エラーが発生してこの変換が妨げられたことを示します。

このメッセージに [SBIE2209](SBIE2209.md) のメッセージが伴わない場合は、Sandboxie サービスが実行されていないことを示している可能性があります。
