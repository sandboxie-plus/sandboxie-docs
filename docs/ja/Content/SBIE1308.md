# SBIE1308


**Message:** SBIE1308 Program cannot start due to restrictions - _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

プログラムが実行されているサンドボックスに対して起動/実行の制限が有効です。プログラムは起動または実行を禁止されています。

関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Restrictions > Start/Run Access](RestrictionsSettings.md#startrun-access)

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [ClosedIpcPath](ClosedIpcPath.md)、[NotifyStartRunAccessDenied](NotifyStartRunAccessDenied.md)
