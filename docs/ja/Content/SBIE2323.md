# SBIE2323


**Message:** SBIE2323 Cryptography error: _[yy / xxxxxxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

[Sandboxie Ini](SandboxieIni.md) 構成ファイルのパスワード保護が有効になっており、Sandboxie がファイルにパスワードを適用しようとしたときに何らかのエラーに遭遇しました。

構成ファイルの保護の詳細については、[Configuration Protection](ConfigurationProtection.md) を参照してください。
