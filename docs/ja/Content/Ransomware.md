# ランサムウェア

あらゆる種類のマルウェアの中で、ランサムウェアは最も破壊的である可能性があります。多くの場合、その悪影響から回復することができないためです。

ほとんどのマルウェアは本質的に妨害的ですが (財務データや資格情報を窃取するバンキング トロイの木馬、知的財産などの情報を標的とするマルウェア、マシンをボットにしてスパム キャンペーンを送信させるものなど)、組織は多大なコスト、労力、時間の後に最終的にその損害から回復できます。

ランサムウェアの場合はそうではありません。重要なビジネス データが永久に失われる可能性があります。

ランサムウェアがデータを人質に取ることができ、ウイルス対策ソフトウェアだけでは止められないことをご存知でしたか?

Sandboxie はプログラムを分離された空間で実行し、マルウェア (ランサムウェアを含む) がコンピューター内の他のプログラムやデータに永続的な変更を加えるのを防ぎます。
