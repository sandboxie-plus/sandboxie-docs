# Portable Sandbox

バージョン 2.80 で導入された[サンドボックスの改訂されたレイアウト](SandboxHierarchy.md)により、コンピューター間でのサンドボックスの移植性が向上します。プログラムをリダイレクトして特定のパスを持たないサンドボックス オブジェクトを作成することで、あるコンピューターでサンドボックスを設定し、そのサンドボックスを別のコンピューターに持ち運んで引き続き使用できます。

たとえば、ドライブ P としてマウントされた USB メモリ スティックなどのポータブル デバイスにゲーム プログラムをインストールすることを考えます。ゲームはそのファイルをドライブ P 上のフォルダーにインストールするかもしれませんが、作成するメニュー ショートカットはドライブ P の外のローカル コンピューターの Windows スタート メニューにインストールされます。また、作成するレジストリ キーも USB デバイスの外の Windows レジストリに作成されます。

対照的に、[コンテナー フォルダー](SandboxMenu.md#set-container-folder)をドライブ P (たとえば _P:\Sandbox_) に設定し、(サンドボックス化された) ドライブ C にゲームをインストールすると、インストールによって作成された_すべての_オブジェクトがドライブ P にリダイレクトされます。

その後、USB ドライブを Sandboxie がインストールされている別のコンピューターに持ち運び、そのコンピューターのコンテナー フォルダーをドライブ P に設定できます。Sandboxie スタート メニューを通じて、ゲームによってインストールされたメニュー ショートカットが表示され、起動すると、ゲームはサンドボックス化されたレジストリに記録されたとおりにその設定を見つけます。

Sandboxie 自体はポータブル ソフトウェアではありませんが、多数のアプリケーションの移植性を容易にすることに注意してください。
