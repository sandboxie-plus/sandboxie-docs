# Copy Limit Kb

_CopyLimitKb_ は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定です。Sandboxie が既存のホスト ファイルの内容をサンドボックスにコピーする必要があるときの、通常のサイズ決定を制御します。制限はキロバイト単位で指定します (1 キロバイト = 1024 バイト)。

詳細については [SBIE2102](SBIE2102.md) を参照してください。

使用法:

```
   .
   .
   .
   [DefaultBox]
   CopyLimitKb=128000
```

この例は、_DefaultBox_ のしきい値を 128000 KiB (125 MiB) に設定します。上書きする移行ルールが適用されない場合、そのしきい値より厳密に小さいファイルが完全な内容の移行に選択されます。しきい値ちょうどのファイル、またはそれより大きいファイルは、大きなファイルのプロンプト/非コピーの決定に入ります。

通常のサイズしきい値を無効にするには `CopyLimitKb=-1` を使用します。それ以外の場合は、適切な正の整数値を使用してください。

## 移行の決定

一致する [DontCopy](DontCopy.md)、[CopyAlways](CopyAlways.md)、および [CopyEmpty](CopyEmpty.md) ルールは、その優先順位でサイズ決定より前に評価されます。いずれも一致せず、有限のしきい値に到達または超過した場合、[PromptForFileMigration](PromptForFileMigration.md) により SandMan がファイルを移行するかどうかを尋ねることができます。肯定的な応答はその試行に対して完全な内容の移行を選択しますが、ソースを読み取れることやコピーが完了することを保証するものではありません。

移行が承認されない場合、[CopyBlockDenyWrite](CopyBlockDenyWrite.md) が初期の移行依存オープンを制御します。`y` はそれを拒否し、それ以外の場合は Sandboxie が書き込みおよび削除アクセスを削除した後にホスト アクセスを再試行します。その再試行は、残りの要求パラメーターまたはホストのアクセス許可が原因で依然として失敗することがあります。

このしきい値はすべてのファイル アクセスを制御するものではありません。新しいファイル、既存のサンドボックス コピーへの通常のアクセス、[OpenFilePath](OpenFilePath.md) を介した直接アクセス、およびホストの内容をコピーしない操作は、別個のパスに従います。[CopyNewer](CopyNewer.md) は既存のサンドボックス コピーの更新を開始できます。その移行の試行は、このサイズ決定を使用できます。

## 有効な値と UI のフォールバック

初期化されたランタイム コンシューマーのフォールバックは `-1` です。有効な値が構成されていない場合、通常のサイズしきい値は無効になります。有効な値は、サンドボックス、該当する有効なテンプレート、または `[GlobalSettings]` フォールバックから取得できます。1 つのサンドボックスに直接値を設定しても、他のサンドボックスの値は変更されません。

インターフェイスには異なる表示フォールバックがあります:

- **SandMan:** 81920 KiB (80 MiB)。直接のボックス設定から読み取られます。有効なサイズ フィールドに `81920` が含まれている場合、保存するとその数値を書き込むのではなく、直接の `CopyLimitKb` エントリが削除されます。その後、該当する継承された構成、またはランタイムの `-1` フォールバックが有効になることがあります。制限のチェックボックスをオフにすると `-1` が書き込まれます。
- **Sandboxie Control Classic:** 49152 KiB (48 MiB)。独自の File Migration UI/アクセサーのフォールバックです。これは現在のランタイム コンシューマーのフォールバックではありません。

表示されるどちらのフォールバックも、普遍的な Sandboxie のサイズ制限を確立するものではありません。サイズ制限とアラート メッセージは [Sandbox Settings > File Migration](FileMigrationSettings.md) で構成できます。

## 変更の適用

この制限は、サンドボックス化されたプロセスがそのファイル サブシステムを初期化するときにキャッシュされます。変更後は影響を受ける新しいサンドボックス化されたプロセスを開始してください。構成を再読み込みしても、既に初期化されたプロセスのキャッシュされた制限は置き換えられません。
