# SBIE2322

**Message:** SBIE2322 Cannot rewrite Sandboxie.ini: _[yy / xxxxxxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は [Sandboxie Ini](SandboxieIni.md) 構成ファイルの内容を書き換えることができませんでした。動作中、[Sandboxie Control](SandboxieControl.md) はサンドボックス設定やその他の情報への変更を反映するために、構成ファイルの内容を時折更新する必要があります。このエラーは、構成ファイルの更新中に問題が発生したことを示します。
