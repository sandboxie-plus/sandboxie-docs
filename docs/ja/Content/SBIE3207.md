# SBIE3207


**Message:** SBIE3207 Cannot find the Internet Explorer executable

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie Start.exe プログラムは、次のレジストリ キーの下に含まれる情報を参照して、Internet Explorer 実行可能プログラム ファイルの場所を特定しようとします:
```
    HKEY_CLASSES_ROOT\Applications\iexplore.exe
```

通常、情報はこのレジストリ キーの既定値に含まれています:
```
    HKEY_CLASSES_ROOT\Applications\iexplore.exe\shell\open\command
```

このエラー メッセージは、必要な情報をレジストリから抽出できなかったことを示します。

**解決策:**

[Sandboxie Control](SandboxieControl.md) の [Add Shortcut Icons](ConfigureMenu.md#windows-shell-integration) 機能を使用して Internet Explorer へのショートカットを直接作成することで、この問題を回避することを検討してください。
