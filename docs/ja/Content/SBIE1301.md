# SBIE1301

**Message:** SBIE1301 Program _program.exe_ was launched outside of the sandbox

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

これは情報/警告メッセージです。

このメッセージは、_Program Alert_ が Sandboxie の監視外で起動されたときに表示されます。

このメッセージは、[Disable Forced Programs](FileMenu.md#disable-forced-programs) モードが有効なときに _Forced Program_ (または _Forced Folder_ のプログラム) が起動された場合にも表示されます。

_Program Alerts_ の構成については、次を参照してください:

*   [Configure Menu -> Program Alerts](ConfigureMenu.md#program-alerts)
*   [Program Settings](ProgramSettings.md#page-1)

_Forced Programs_ の構成については、次を参照してください:

*   [SandboxSettings > Forced Programs](ProgramStartSettings.md#forced-programs)
*   [SandboxSettings > Forced Folders](ProgramStartSettings.md#forced-folders)
*   [Program Settings](ProgramSettings.md#page-1)
