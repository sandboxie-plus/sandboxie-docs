# SBIE1105

**Message:** SBIE1105 Unknown operating system version: _x.yy_

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。ドライバー コンポーネントはオペレーティング システムの中核 (カーネルとも呼ばれます) に統合されます。この統合がシームレスに機能するには、ドライバーがオペレーティング システムを認識する必要があります。このメッセージは、ドライバーがオペレーティング システムを認識しなかったことを示します。

このメッセージの後に [SBIE1103](SBIE1103.md) のメッセージが続きます。
