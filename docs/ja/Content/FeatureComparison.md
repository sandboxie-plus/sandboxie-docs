Sandboxie Plus と Classic は同じコア コンポーネントを共有しています。主な違いは、Classic UI がもはや開発されていないため、新しいコア機能の UI は Sandboxie-Plus の SandMan UI でのみ利用できることです。その他のさまざまな新機能も SandMan UI でのみ実装されています。

多くの限定機能は、有効な[サポーター証明書](https://sandboxie-plus.com/supporter-certificate/)を持つプロジェクト サポーターのみが利用できます。以下の表を参照してください。

バージョン 1.11.0 以降、[Advanced Feature Pack](https://xanasoft.com/product/sandboxie-plus-advanced-upgrade/)も利用可能です。サンドボックス暗号化、プロキシ インジェクション、または DNS フィルタリングを使用するには、サポーター証明書に加えてこれを取得する必要があります。[Contributor](https://sandboxie-plus.com/contribute/) および [Eternal](https://xanasoft.com/product/sandboxie-plus-eternal/) 証明書には、既定ですべての Advanced オプションが含まれています。

**Sandboxie Plus を商用または教育目的で使用するには、[Business 証明書](https://xanasoft.com/product/sandboxie-plus-business/)が必要であることに注意してください!**
