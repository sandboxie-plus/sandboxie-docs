# SBIE2314


**Message:** SBIE2314 Canceling process _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Windows の更新により、Windows 7 で Sandboxie がこのメッセージを発行することがあります。


**COM サーバー**

特定の場合において、Sandboxie は、要求元がサンドボックス外にあるとき、サンドボックス内で開くべきファイル名を受け取るために、Internet Explorer、Window Media Player、またはその他のメディア プレーヤーのインスタンスを起動する必要がある場合があります。

たとえば、Window Media Player がサンドボックス内で強制的に実行され、Windows Explorer (サンドボックス外で実行中) を通じてメディア ファイルを開く要求が行われた場合、Sandboxie はメディア ファイルのファイル名を受け取るために Windows Media Player のインスタンスを起動する必要があり、その後、Window Media Player の適切にサンドボックス化されたインスタンスを開いてファイルを再生できます。

このメッセージは、この方法でファイル名を受け取るために起動されたプログラムが何らかのエラーに遭遇し、閉じなければならなかったことを示します。

**Internet Explorer およびメディア プレーヤーの場合:**

バージョン 3.32 以降、このメッセージは Internet Explorer プログラム _iexplore.exe_ に対してのみ、かつ Internet Explorer が[強制プログラム](ProgramStartSettings.md#forced-programs)として構成されている場合にのみ発行されます。

このメッセージは、サンドボックス外で実行されているプログラムからインターネット アドレス (URL) を受け入れるために起動された Internet Explorer の特別なインスタンスがエラーに遭遇したことを示します。

[Disable Forced Programs](FileMenu.md#disable-forced-programs) コマンドを呼び出し、インターネット アドレスを開く操作を再試行することで、この問題を回避できるはずです。
