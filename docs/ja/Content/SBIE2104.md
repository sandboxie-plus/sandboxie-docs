# SBIE2104


**Message:** SBIE2104 Denied attempt to end this Windows session

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

これは情報メッセージです。

Sandboxie の監視下で実行されているプログラムは、アクティブ ユーザーをログオフするか、システムをシャットダウンまたは再起動するために必要な特権が削除されています。

このメッセージは、サンドボックス化されたプログラムがログオフ、シャットダウン、または再起動を通じて Windows セッションを終了することを要求し、その要求が拒否されたことを示します。
