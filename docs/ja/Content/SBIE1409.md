# SBIE1409

**Message:** SBIE1409 The Templates.ini file cannot be opened _[xxxxxxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、インストール フォルダーにグローバル構成ファイル _Templates.ini_ があることを期待しています。このファイルはインストールの標準的な一部と見なすべきであり、編集または削除しないでください。
