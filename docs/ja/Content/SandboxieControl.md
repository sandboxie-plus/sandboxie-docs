# Sandboxie Control

### 概要

Sandboxie Control は Sandboxie Classic のグラフィカル フロントエンドであり、Sandboxie のほとんどの側面を制御できます。これを使用してできることの一部を次に示します。

*   Sandboxie の監視下でプログラムを起動および停止する
*   サンドボックス内のファイルを表示する
*   サンドボックスから必要なファイルを復元する
*   サンドボックスの内容を削除し、不要なファイルをすべて消去する
*   サンドボックスを作成、削除、構成する

### 表示/非表示

Sandboxie は主に他のプログラムを実行するための仕組みであり、対話型のツールではありません。通常は Sandboxie Control のメイン ウィンドウを非表示にし、プログラムは画面の通常右下隅にあるシステム通知領域のトレイ アイコンとしてのみ表示されます。

![](../Media/TrayIcon.png)

（時計の近くにある黄色い Sandboxie Control アイコンに注目してください。）

非表示状態を切り替えるには、トレイ アイコンをダブルクリックするか、右クリックして _Show Window_（ウィンドウを表示）または _Hide Window_（ウィンドウを隠す）コマンドを選択します。（[トレイ アイコン メニュー](TrayIconMenu.md)を参照してください。）また、ウィンドウ右上隅の閉じるボタン (X) をクリックしてウィンドウを非表示にすることもできます。

Sandboxie Control を終了し、システム通知領域からトレイ アイコンを削除するには、トレイ アイコンを右クリックして _Exit_（終了）を選択します。
