# Show For Run in

ShowForRunIn は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定です。「run in box」選択プロンプトにこのボックスを表示するかどうかを指定します。
```
   .
   .
   .
   [DefaultBox]
   ShowForRunIn=n
```

_n_ を指定すると、このサンドボックスは「run in sandbox」選択ウィンドウの候補として表示されないことを示します。

関連する Sandboxie Plus 設定: Sandbox Options > General Options > Box Options > Show this box in the 'run in box' selection prompt
