# SBIE1411

**Message:** SBIE1411 Sandbox %2 specifies unknown template %3

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、_Sandboxie.ini_ ファイルの処理中にエラーが発生しました。このファイルで構成されているサンドボックスの 1 つが、グローバル構成ファイル _Templates.ini_ に存在しないグローバル テンプレート セクションを参照しています。

ローカル テンプレートは _Sandboxie.ini_ ファイルで定義すべきであり、標準のグローバル テンプレートは Sandboxie のインストールの一部として _Templates.ini_ ファイルで提供されることに注意してください。
