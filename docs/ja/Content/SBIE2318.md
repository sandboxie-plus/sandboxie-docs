# SBIE2318


**Message:** SBIE2318 DLL initialization failed for _library.dll_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックス化されたプログラムは、メッセージに記載されたシステム DLL を読み込む要求を発行しました。サンドボックス化されたプログラムに課せられた制限のために、一部のシステム DLL の一部の機能はサンドボックス化して実行すると「そのままでは」機能しません。これらの場合、Sandboxie はタスクを達成するのを支援するために DLL を変更する必要があります。

このメッセージは、Sandboxie がシステム DLL を「修正」できなかったことを示します。
