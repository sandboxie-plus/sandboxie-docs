# SBIE2214

**Message:** SBIE2214 Request to start service _name_ was denied due to dropped rights

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックスで [Drop Rights](RestrictionsSettings.md#drop-rights) 設定が有効になっており、これによりサービス プログラムが完全な (LocalSystem) 特権で起動するのを妨げています。

64 ビット版の Sandboxie では [Drop Rights](RestrictionsSettings.md#drop-rights) 設定が既定で有効になっていることに注意してください。

このメッセージの後に [SBIE2219](SBIE2219.md) のメッセージが続きます。

**解決策:** [Drop Rights](RestrictionsSettings.md#drop-rights) 設定をオフにします。
