# SBIE1311

**OBSOLETE**

**Message:** SBIE1311 Blocked request to change desktop wallpaper by process _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、プログラムがデスクトップの壁紙を変更する要求を発行したことを検出し、要求をブロックしました。

関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Restrictions > Low-Level Access](RestrictionsSettings.md#low-level-access-removed)

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [BlockSysParam](BlockSysParam.md)
