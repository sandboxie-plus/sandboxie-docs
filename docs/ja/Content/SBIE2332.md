# SBIE2332


**Message:** SBIE2332 Cannot access file SbiePst.dat

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

_SbiePst.dat_ ファイルはサンドボックス内に作成され、Sandboxie が Protected Storage 機能を実装するために使用します。このエラー メッセージは、Sandboxie が _SbiePst.dat_ ファイルの作成またはアクセスで問題に遭遇したことを示します。

詳細については、[Protected Storage](ProtectedStorage.md) を参照してください。
