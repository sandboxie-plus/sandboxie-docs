# SBIE9153


**Message:** SBIE9153 Cannot start driver (SbieDrv)

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のサービス コンポーネント (SbieSvc) が Sandboxie のドライバー コンポーネント (SbieDrv) を起動できませんでした。その情報が不明であるため、メッセージはエラーの原因を特定しません。

エラーの考えられる原因:

*   ドライバー コンポーネント SbieDrv が正しくインストールされていません。Sandboxie を上書き再インストール (更新/アップグレード インストール) してみてください。それで問題が解決しない場合は、Sandboxie をアンインストールし、新規コピーを再インストールしてみてください。

*   ドライバーが Windows によってブロックされています。Windows からの関連メッセージがないか [System Event Log](SystemEventLog.md) を確認してください。

*   ドライバーがサードパーティのセキュリティ ソフトウェアによってブロックされています。サードパーティのセキュリティ ソフトウェアのドキュメントを参照してください。
