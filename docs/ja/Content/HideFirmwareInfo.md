# Hide Firmware Info

HideFirmwareInfo は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定です。

```ini
[DefaultBox]
HideFirmwareInfo=y
```

有効で `SMBiosTable` データが利用可能な場合、Sandboxie はインターセプトされた `RSMB` SMBIOS ファームウェア テーブルの `Get` クエリに対して返されるバイトをそのデータで置き換えます。他のファームウェア テーブル プロバイダーとアクションは元のクエリ パスを通じて続行されます。この設定は、すべてのファームウェア API または WMI クエリのカバレッジを確立するものではありません。

## SMBIOS テーブル データ

このフックは、サンドボックス化されたプロセスの通常のレジストリ ビューを通じて `HKCU\System\SbieCustom` から `SMBiosTable` を読み取ります。`SMBiosTable` はレジストリ値であり、INI 設定ではありません。このフックはサンドボックスを明示的に検索してからホストを検索するわけではありません。ホストまたはサンドボックス化された値の可視性は、通常のレジストリ仮想化に従います。この設定は、このデータが有効なレジストリ ビューを通じて利用可能であることを前提としています。欠落または無効なカスタム データは、ホストの SMBIOS テーブルへの文書化されたフォールバックとして扱うべきではありません。

**Sandbox Options > Advanced Options > Privacy** で、**Hide Firmware Information** チェックボックスがボックスの直接の設定を制御します。**Dump FW Tables** はホストの `RSMB` テーブルを読み取り、ホスト ユーザーの `HKCU\System\SbieCustom` の下にバイナリ `SMBiosTable` 値として保存します。ボックス固有のテーブルが必要な場合、その値をサンドボックス化されたレジストリにコピーできます。テーブルをダンプしても `HideFirmwareInfo` は有効になりません。

有効な値が構成されていない場合、ランタイム フォールバックは無効です。ブールの照会はサンドボックス化されたプロセス イメージによって修飾でき、該当するテンプレートまたはグローバル構成を含めることができます。したがって、チェックボックスのボックス直接の値は有効な値と異なることがあります。ブールはインターセプトされたクエリ時にチェックされるため、更新された有効な値は、そのプロセスに `NtQuerySystemInformation` フックが既にインストールされていれば以降の呼び出しに影響を与えることがあります。構成の変更によって、プロセスの初期化時にスキップされたフックを遡ってインストールすることはできません。
