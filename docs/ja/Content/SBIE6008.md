# SBIE6008

**Message** SBIE6008 The configuration %3 of box %2 requires a supporter certificate and can not be used without it.

**Severity**: Error (popup)

## 説明

このエラーは、ボックス構成がサポーター証明書を必要とする機能を使用しており、システムにその構成の使用を許可する有効な証明書がないときに表示されます。証明書要件と猶予期間について警告する SBIE6004 とは異なり、SBIE6008 は証明書なしでは構成をまったく使用できないことを示します。

## 一般的な原因

- ボックス構成が、サポーター証明書によってゲートされる 1 つ以上の機能 (たとえば特定の暗号化またはセキュリティ モード設定) を有効にしている。
- サポーター証明書がインストールされていないか、インストールされた証明書が有効/アクティブでない。
- 証明書に特定の構成に必要なオプション フラグが欠けている。

## 推奨される操作

1. メッセージが参照する構成を確認し (%3 は構成識別子です)、証明書を提供する予定がない場合はサポーター証明書を必要とする機能を無効にします。
2. その構成に必要なオプション フラグを含むサポーター証明書をインストールしてアクティブにします。
3. 証明書のインストール後に Sandboxie サービスとドライバーを再起動して、新しい証明書が検出されるようにします。
4. 構成が証明書なしで使用可能であるべき場合は、機能フラグを確認し、ドライバー/サービス ログを参照して証明書チェックが失敗した理由を見つけてください。
