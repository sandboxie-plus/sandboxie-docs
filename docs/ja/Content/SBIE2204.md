# SBIE2204


**Message:** SBIE2204 Cannot start sandboxed service _name__(xxxxxxxx)_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは、Sandboxie がヘルパー プログラム _SandboxieRpcSs_ または _SandboxieDcomLaunch_ の 1 つを起動できなかったことを示します。メッセージに記載される名前は _rpcss_ または _dcomlaunch_ です。

これらのプログラムの詳細については、[Service Programs](ServicePrograms.md) を参照してください。
