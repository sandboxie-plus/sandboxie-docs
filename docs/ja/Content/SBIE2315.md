# SBIE2315


**Message:** SBIE2315 Could not fix executable image

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

メッセージ [SBIE1214](SBIE1214.md) で説明したように、Sandboxie ドライバーは、サンドボックス内で起動されたサンドボックス化されたプログラムに Sandboxie DLL コンポーネントをインジェクトします。

DLL コンポーネントがサンドボックス化されたプログラム内で実行を開始すると、まずインジェクションの副作用を「クリーンアップ」する必要があります。このメッセージは、エラーが発生し、クリーンアップができないことを示します。
