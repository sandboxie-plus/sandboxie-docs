# SBIE1410

**Message:** SBIE1410 The following message indicates an error in the Templates.ini file

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、グローバル構成ファイル _Templates.ini_ の処理中にエラーが発生しました。

このメッセージは、他の SBIE14xx メッセージ ([SBIE1402](SBIE1402.md)、[SBIE1403](SBIE1403.md)、[SBIE1404](SBIE1404.md)、[SBIE1405](SBIE1405.md)、[SBIE1406](SBIE1406.md)) の 1 つの前に続きます。

このメッセージは、後続の SBIE14xx メッセージが _Sandboxie.ini_ 構成ファイルではなく _Templates.ini_ ファイルを参照していることを示します。
