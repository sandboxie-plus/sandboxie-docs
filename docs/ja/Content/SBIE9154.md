# SBIE9154


**Message:** SBIE9154 Driver (SbieDrv) and service (SbieSvc) have different version numbers

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のサービス コンポーネント (SbieSvc) のバージョン番号が、ドライバー コンポーネント (SbieDrv) と異なります。この問題を解決するには、Sandboxie を上書き再インストール (更新/アップグレード インストール) してみてください。それで問題が解決しない場合は、Sandboxie をアンインストールし、新規コピーを再インストールしてみてください。
