# CPU Affinity Mask

_CpuAffinityMask_ は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定で、Sandboxie Plus 1.13.5 以降で利用できます。各プロセスが初期化されるときにプロセッサ アフィニティ マスクを適用することにより、サンドボックス化されたプロセスを選択された論理プロセッサに制限します。

## 使用法

```ini
[DefaultBox]
CpuAffinityMask=0x00000003
```

値は 16 進数で `0x` または `0X` で始まる必要があります。設定された各ビットが対応する論理プロセッサを許可します。この例では、ビット 0 と 1 が設定されているため、サンドボックス化されたプロセスは論理プロセッサ 0 と 1 で実行できます。論理プロセッサは、物理 CPU コアと必ずしも 1 対 1 で対応するわけではありません。

## 現在の制限

現在の Sandboxie 実装は、論理プロセッサ インデックス 0 から 31 のみをサポートします。論理プロセッサ 32 以降のビットは、64 ビット Windows でもこの設定で構成できません。

Sandboxie は 1 つのアフィニティ マスクを公開しますが、プロセッサ グループ セレクター、`GROUP_AFFINITY` 設定、または CPU Sets 設定は公開しません。したがって、複数の Windows プロセッサ グループを使用するシステムでは、マスクは Windows の単一グループ アフィニティ セマンティクスの対象となり、別のグループのプロセッサを明示的に選択できません。

Windows が要求されたアフィニティ マスクを拒否した場合、現在の Sandboxie はその失敗を理由にプロセスを終了しません。_CpuAffinityMask_ が構成されていない場合、Sandboxie はこの設定のプロセッサ アフィニティ制限を適用しません。

_CpuAffinityMask_ は、サンドボックス化されたプロセスがどこで実行されるかを制御します。それらの集約プロセッサ スケジューリング容量を制限するには、[CPU Rate Limit](CpuRateLimit.md) を参照してください。2 つの設定は一緒に使用できます。
