# SBIE1214

**OBSOLETE**

**Message:** SBIE1214 Cannot inject SbieDll _[xxxxxxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie ドライバー コンポーネントは、サンドボックス内で起動されたサンドボックス化されたプログラムに Sandboxie DLL コンポーネントをインジェクト (読み込み) できませんでした。

このエラーはほとんど発生しませんが、発生する場合は通常、非常に小さなプログラムまたは非常に大きく複雑なプログラムで発生します。いずれの場合も、[UPX](https://upx.github.io) を使用してプログラムの実行可能ファイルを圧縮することでこのエラーを回避できる可能性があります。
