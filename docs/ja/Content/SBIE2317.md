# SBIE2317

**Message:** SBIE2317 Cannot initialize path list '%2'

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックス内でプログラムが起動するたびに、Sandboxie は [Sandboxie Ini](SandboxieIni.md) ファイルの構成設定をそのプログラムに適用します。このエラー メッセージは、_name_ の構成設定を準備する際に問題が発生したことを示します。

_name_ は [OpenFilePath](OpenFilePath.md)、[OpenPipePath](OpenPipePath.md)、[ClosedFilePath](ClosedFilePath.md)、[ReadFilePath](ReadFilePath.md)、[OpenKeyPath](OpenKeyPath.md)、[ClosedKeyPath](ClosedKeyPath.md)、[ReadKeyPath](ReadKeyPath.md)、[OpenIpcPath](OpenIpcPath.md)、[ClosedIpcPath](ClosedIpcPath.md)、または [OpenWinClass](OpenWinClass.md) のいずれかです。

このメッセージは [SBIE1203](SBIE1203.md) のメッセージに似ています。
