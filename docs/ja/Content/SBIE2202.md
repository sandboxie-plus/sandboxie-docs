# SBIE2202

**Message:** SBIE2202 Missing list of installed hardware devices

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックス化されたプログラム内で実行されている Sandboxie DLL コンポーネントは、Sandboxie サービス コンポーネント (SbieSvc) によって事前に準備された情報にアクセスする必要があります。

このメッセージは、情報が利用できなかったことを示します。通常、その理由は Sandboxie サービスが実行されていないことです。
