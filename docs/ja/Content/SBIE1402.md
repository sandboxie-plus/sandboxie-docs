# SBIE1402

**Message:** SBIE1402 Configuration file error in line _number_: _[xxxxxxxx]_

**ログ記録先:** [System Event Log](SystemEventLog.md) と [Popup Message Log](PopupMessageLog.md)

**説明:**

[Sandboxie Ini](SandboxieIni.md) 構成ファイルの読み取り中に何らかのエラーが発生しました。

メッセージ [SBIE1403](SBIE1403.md)、[SBIE1404](SBIE1404.md)、および [SBIE1405](SBIE1405.md) は特定のエラー条件に関するものですが、このメッセージはその他の不特定の条件を示すことに注意してください。
