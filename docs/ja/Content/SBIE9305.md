# SBIE9305


**Message:** SBIE9305 Terminate sandboxed programs, if any are running

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のサービス コンポーネント (SbieSvc) が、プロセス間共有メモリ セクションに関連する何らかのエラーに遭遇しました。

このメッセージは [SBIE9302](SBIE9302.md) および [SBIE9304](SBIE9304.md) のメッセージに続き、通常、1 つ以上のプログラムがサンドボックス化して実行されている間に Sandboxie サービスが再起動されたときに発生するエラー状態を示します。
