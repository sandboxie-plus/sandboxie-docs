# SBIE2313

**Message:** SBIE2313 Could not execute _program.exe_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は自身のプログラムの 1 つを実行できませんでした。Sandboxie インストール フォルダーへのアクセス許可を確認するか、Sandboxie を再インストールしてください。

**考えられる原因**

*   Sandboxie が、そのプログラム ファイルを含むフォルダーへのアクセスをブロックするように構成されていました。[Sandbox Settings > Resource Access > File Access > Blocked Access](ResourceAccessSettings.md#file-access-blocked-access) を参照してください。

*   サードパーティ (HIPS) セキュリティ ソフトウェアが、メッセージに記載されたプログラムの実行をブロックするように構成されていました。

**既知の競合**

メッセージ: SBIE2313 Could not execute SandboxieDcomLaunch.exe

これは、ファイアウォール ソフトウェアで Enhanced Security Verification (ESV) 機能が有効になっていた場合、Sandboxie と 5.0.0.38 より前の PC Tools Firewall Plus のバージョンの組み合わせによって発生する可能性があります。

この競合を解決するには、PC Tools Firewall Plus のバージョン 5.0.0.38 以降にアップグレードしてください。
