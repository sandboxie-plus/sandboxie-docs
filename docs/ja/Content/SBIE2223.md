# SBIE2223

**Message:** SBIE2223 To increase the file size limit for copying files, please double-click on this message line

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie Control Classic では、このメッセージは非表示でない [SBIE2102](SBIE2102.md) に続き、ファイル移行のサイズ制限を調整する簡単な方法を提供します。メッセージをダブルクリックすると確認フローが開き、サンドボックスの [CopyLimitKb](CopyLimitKb.md) を増やすことができます。SandMan は同じフォローアップ ショートカットを提供しません。

この制限は、初期化されたサンドボックス化されたプロセスにキャッシュされます。変更後は影響を受ける新しいプロセスを開始してください。このショートカットは既存のキャッシュされた制限を更新しません。

関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > File Migration](FileMigrationSettings.md)

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [CopyLimitKb](CopyLimitKb.md)
