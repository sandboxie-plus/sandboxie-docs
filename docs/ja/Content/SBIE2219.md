# SBIE2219

**Message:** SBIE2219 Request was issued by program '_name_'

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは、完了できなかった操作を発行したプログラム (「_name_」として識別) を名指しします。失敗の理由を含む要求に関する詳細は、メッセージ SBIE2219 より前に続く [SBIE2214](SBIE2214.md)、[SBIE2217](SBIE2217.md)、または [SBIE2218](SBIE2218.md) のいずれかによって示されます。
