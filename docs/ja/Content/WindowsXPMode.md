# Windows XP Mode

Windows 7 では、Microsoft は _Windows XP Mode_ を提供しています。これは、プライマリの Windows 7 オペレーティング システムと並行して実行される 32 ビット Windows XP Service Pack 3 の仮想化インストールです。

#### Windows XP Mode は Windows 7 の Professional、Enterprise、および Ultimate エディションでのみ使用できます。

Sandboxie の 32 ビット版は、64 ビット Windows 7 内で実行される 32 ビット Windows XP にインストールできます。_Windows XP Mode_ の Windows 7 環境へのシームレスな統合のおかげで、32 ビット Sandboxie は 64 ビット Windows 7 内でかなりうまく機能します。

_Windows XP Mode_ は、Windows XP を実行するスタンドアロン仮想マシンよりも使いやすく、Windows 7 によりよく統合されています。また、ライセンスされた Windows XP のコピーも含まれています。ただし、この改善された統合により、_Windows XP Mode_ オペレーティング システムから発信される悪意のある変更に Windows 7 システムとドキュメントがさらされます。

Sandboxie を使用すると、独自のサンドボックス内で分離された Web ブラウザーを持つことができ、Windows 7 上で直接実行される Web ブラウザーよりも安全になります。

> [Windows XP Mode - Install and Setup](https://www.sevenforums.com/tutorials/8247-windows-xp-mode-install-setup.html)

_Windows XP Mode_ が Windows 7 にインストールされたら、Sandboxie と Firefox をインストールするための手順は次のとおりです:

*   _Windows XP Mode_ オペレーティング システムを開きます。
*   オプションで、Firefox をダウンロードしてインストールします。インストール プロセス中に Firefox が自身を既定の Web ブラウザーとして指定できるようにしてください。オプションで、Firefox の設定を微調整し、使用したいアドオンをインストールします。
*   Sandboxie をダウンロードしてインストールします。
*   オプションで、_Windows XP Mode_ オペレーティング システム用のアンチウイルスをダウンロードしてインストールします。
*   _Windows XP Mode_ オペレーティング システムからログアウトします。
*   Windows 7 スタート メニューで、Sandboxie プログラム グループが見つかるはずです: _Windows 7 Start Menu > All Programs > Windows Virtual PC > Windows XP Mode Applications > Sandboxie_
*   _Run Web browser sandboxed_ を選択して、Sandboxie 内で Firefox を実行します。
