# SBIE1303

**OBSOLETE**

**Message:** SBIE1303 Only one sandbox can be active at a time

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このエラー メッセージは、未登録版の Sandboxie で、複数のサンドボックスで同時にプログラムが起動されたときに表示されました。未登録版には、一度に 1 つのサンドボックスでしかプログラムを実行できないという制限がありました。

この制限は Sandboxie 5.31.4 以降には存在しません。
