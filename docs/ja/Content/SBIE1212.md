# SBIE1212

**Message:** SBIE1212 Cannot create directory _path__[xxxxxxxx]_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

Sandboxie は、_path_ で識別されるサンドボックス フォルダーを作成しようとしたときにエラーが発生しました。

サンドボックス フォルダーの場所を変更するには、[Sandbox Menu -> Set Container Folder](SandboxMenu.md#set-container-folder) を使用するか、[FileRootPath](FileRootPath.md) 構成設定を手動で編集します。
