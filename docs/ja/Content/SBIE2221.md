# SBIE2221

**Message:** SBIE2221 To add the program to Internet Access Restrictions, please double-click on this message line

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

このメッセージは [SBIE1307](SBIE1307.md) のメッセージに続き、プログラムをインターネット アクセス制限に追加する簡単な方法を提供します。

関連する [Sandboxie Control](SandboxieControl.md) 設定: [Sandbox Settings > Restrictions Settings > Internet Access](RestrictionsSettings.md#internet-access)

関連する [Sandboxie Ini](SandboxieIni.md) 設定: [ClosedFilePath](ClosedFilePath.md)、[NotifyInternetAccessDenied](NotifyInternetAccessDenied.md)
