# Skip Hook

`SkipHook` は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定で、Sandboxie が特定のモジュールまたはフック識別子に対して特定のフックをインストールするのを防ぐために使用されます。`Dll_SkipHook` ヘルパーを使用する呼び出し元によって参照されます。

この設定は、コンマ区切りの識別子リストが関数ごとのリストよりも便利な、モジュールまたはフック名レベルでの除外に使用します。

## 構文

```ini
[DefaultBox]

; Skip hooks for specific module/hook identifiers (comma-separated list)
SkipHook=[<program>,]<entry1>,<entry2>,...
```

注:

- エントリはコンマ区切りのトークンです。各トークンは、オプションでプログラム/イメージ名の後にコンマを付けてプレフィックスできます (例: `PotPlayer64.exe,cocreate`)。これはトークンを特定のプログラムに限定します。プログラム プレフィックスが存在する場合、残りのトークンはそのプログラムに対してのみ適用されます。
- 各トークン (オプションのプログラム プレフィックスの後の部分) は、大文字と小文字を区別しないプレフィックス比較を使用して、要求されたフック名と比較されます。[^1]
- すべてのフック インストール パスが必ずしも `Dll_SkipHook` を参照するわけではないため、`SkipHook` がすべてのフック試行を防ぐとは限りません。

## 使用方法

通常、特定のアプリケーションまたはフック識別子に対するフッキングを避けるためにテンプレートで使用されます。

例:

```ini
[DefaultBox]

SkipHook=DragonSaga.exe,enumwin,findwin
SkipHook=PotPlayer64.exe,cocreate
```

## 動作

- 呼び出されると、`Dll_SkipHook` は現在のイメージ/テンプレートに対して構成された `SkipHook` 文字列を読み込み、コンマ区切りのトークンをスキャンします。トークンが要求されたフック名の先頭と一致する場合 (大文字と小文字を区別せず)、ヘルパーは true を返し、呼び出し元はそのフックのインストールをスキップできます。
- このチェックはすべてのフック インストール ポイントで普遍的に使用されているわけではないため、`SkipHook` にリストされていても一部のフックはインストールされる可能性があります。

## GUI

`SkipHook` は高度な設定であり、通常は INI で手動で編集されます。Sandboxie に同梱されるテンプレート ファイルには `SkipHook` エントリの例が含まれていることがあります。

## 関連設定

- [FuncSkipHook](FuncSkipHook.md) — 特定の API 関数のフッキングをスキップする関数レベルの設定。

## 脚注

[^1]: `Dll_SkipHook` は `SbieDll_GetSettingsForName(..., L"SkipHook", ...)` で内部バッファーを初期化し、コンマ区切りのトークンをスキャンします。一致は大文字と小文字を区別しないプレフィックス比較 (`_wcsnicmp`) を使用して実行されます。
