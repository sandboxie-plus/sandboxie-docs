# Breakout Folder

_BreakoutFolder_ は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定で、Sandboxie Plus 1.0.8 / Classic 5.55.8 以降で利用できます。サンドボックス化されたプロセスが起動しようとしている実行可能ファイルのディレクトリ部分を照合します。そのディレクトリ内のファイルへの任意のアクセスをサンドボックス外にするものではありません。

```ini
[DefaultBox]
BreakoutFolder=C:\Example
BreakoutFolder=C:\OtherApp\*
BreakoutFolder=C:\?pp\*
```

最初のルールは `C:\Example` 直下の実行可能ファイルを照合しますが、そのサブディレクトリを自動的に照合しません。2 番目は `*` を使用して `C:\OtherApp` より下の実行可能ディレクトリを照合します。`C:\OtherApp` 直下の実行可能ファイルは含まれません。ディレクトリ自体とそのサブディレクトリの両方を照合する必要がある場合は、別個のルールを追加してください。

`BreakoutFolder` は大文字と小文字を区別しないパターン マッチングを使用し、`*` と `?` をサポートします。たとえば `C:\App?` は、実行可能ディレクトリ名の 1 文字違いのバリエーションを照合できます。組み合わせた `C:\?pp\*` の例は、`App` のような名前より下のディレクトリを照合しますが、`C:\App` 直下の実行可能ファイルは照合しません。ディレクトリ文字列は意図的に照合してください。末尾の `\` は、そのスラッシュのないディレクトリ名と互換ではありません。`E:\` のようなドライブ ルートのみのエントリは、ドライブ全体に対するルールではありません。

ショートカット起動の場合、関連するディレクトリは、ショートカットを含むディレクトリではなく、新しいプロセスに対して実際に選択された実行可能ファイルのディレクトリです。`C:\Example` 内のショートカットが `C:\Tools\viewer.exe` を指している場合、ショートカットの場所だけを理由に `BreakoutFolder=C:\Example` と一致することはありません。一致する起動は、別の有効なサンドボックスの [Force Process](ForceProcess.md) または [Force Folder](ForceFolder.md) ルールによって捕捉されることがあります。ブレイクアウトはサンドボックス外の宛先を保証しません。

この設定は将来のプロセス起動に影響し、既存のプロセスや一般的なファイル アクセスには影響しません。サービス検証、セキュリティへの影響、および SandMan コントロールについては [Breakout Execution](BreakoutExecution.md) を参照してください。[Breakout Process](BreakoutProcess.md) とは異なり、このルールは実行可能ファイルに対してサービスの別個のホスト ファイル チェックを使用しません。
