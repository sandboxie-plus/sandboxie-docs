# BorderExcludeTaskbar

_BorderExcludeTaskbar_ は [Sandboxie Ini](SandboxieIni.md) のサンドボックス設定で、Sandboxie Plus 1.17.3 以降で利用できます。既定で有効です。

```ini
[DefaultBox]
BorderExcludeTaskbar=y
```

この設定は、Sandboxie Plus (SandMan) によって描画される視覚的な境界オーバーレイにのみ影響します。サンドボックス化されたアプリケーションのウィンドウを移動、サイズ変更、またはクリップするものではありません。

## 境界オーバーレイの動作

Sandboxie Plus は、色付きの枠と、省略可能なサンドボックス名またはエイリアスのラベルを、別個のオーバーレイ ウィンドウに描画します。_BorderExcludeTaskbar_ が有効な場合、SandMan は各モニターの報告された作業領域から除外された領域の周囲でそのオーバーレイをクリップします。これらの領域には通常、Windows タスクバーが含まれ、他の登録済みアプリバーまたは予約済みデスクトップ領域が含まれることもあります。

クリップ ロジックは、各ディスプレイについて報告されたモニターおよび作業領域の矩形から除外を導出するため、モニターを認識し、複数のモニター上の予約済み作業領域を考慮できます。正確な結果は Windows が報告する情報に依存します。自動非表示のタスクバー、特殊なシェル置換、および特殊なアプリバーの配置は異なる動作をする場合があります。

最前面の動作を使用するサンドボックス化されたターゲット ウィンドウは、この境界オーバーレイのクリップから除外されます。これはオーバーレイ描画の例外であり、基になるアプリケーションにタスクバーの動作を変更する許可を与えるものではありません。

色付きの枠とサンドボックス ラベルは同じオーバーレイに描画されるため、除外は、予約済み作業領域と交差する両方の位置に影響します。これにはラベル指向の境界モードも含まれます。

_BorderExcludeTaskbar_ は、Sandboxie Plus が視覚的なサンドボックス境界またはラベルを表示している間のみ意味があります。境界の表示が無効な場合、この設定がクリップするオーバーレイはありません。[Border Color](BorderColor.md) を参照してください。

## 構成と実行時の動作

この設定はサンドボックスごとに構成できます。グローバル構成の値はフォールバックとして機能し、既定は有効です。文書化されたプログラムごとの構文はありません。

これは SandMan のオーバーレイ動作であるため、設定を変更してもサンドボックス化されたアプリケーションを再起動する必要はありません。変更は、境界領域が再構築されるときに適用されます。フォーカスされたウィンドウの境界モードでは、変更された除外が表示される前に、対象ウィンドウの再フォーカス、移動、またはサイズ変更が必要になることがあります。

現在、通常の Sandbox Options インターフェイスには _BorderExcludeTaskbar_ 専用のチェックボックスはありません。INI 構成を通じて構成してください。

## バージョン履歴

_BorderExcludeTaskbar_ は Sandboxie Plus 1.17.3 で導入されました。当初は全ウィンドウ境界の動作に関連付けられていましたが、現在の実装ではフォーカスされたウィンドウの境界モードにも適用されます。その既定は引き続き有効です。
