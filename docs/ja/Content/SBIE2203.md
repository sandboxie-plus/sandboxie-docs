# SBIE2203


**Message:** SBIE2203 Failed to communicate with Sandboxie Service: _detail_

**ログ記録先:** [Popup Message Log](PopupMessageLog.md)

**説明:**

サンドボックス化されたプログラム内で実行されている Sandboxie DLL コンポーネントは、Sandboxie サービス コンポーネント (SbieSvc) と通信する必要があります。このメッセージは、何らかの通信障害が発生したことを示します。

_detail_ が _connect_ の場合、考えられる理由は Sandboxie サービスが実行されていないことです。

_detail_ のその他の値は、通信は確立されたが、何らかのエラーにより完了できなかったことを示します。
