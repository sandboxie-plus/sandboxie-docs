# SBIE1110

**Message:** SBIE1110 Cannot intercept type _name_, error _[[ntstatus](NtStatusCodes.md) / yy]_

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。このメッセージは、ドライバーがオペレーティング システムに統合できなかったことを示します。

このメッセージの後に [SBIE1103](SBIE1103.md) のメッセージが続きます。
