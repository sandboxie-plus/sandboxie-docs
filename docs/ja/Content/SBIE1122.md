# SBIE1122

**Message:** SBIE1122 Error: _[[ntstatus](NtStatusCodes.md)]_

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。このメッセージは、Sandboxie が何らかのシステム サービスを傍受して拡張できなかったことを示します。

このメッセージの後に、エラーが発生したシステム サービスの名前を指定する [SBIE1121](SBIE1121.md) のメッセージが続きます。
