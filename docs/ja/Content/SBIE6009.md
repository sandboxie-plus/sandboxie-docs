# SBIE6009

**Message**

SBIE6009 The configuration %3 of box %2 requires an advanced supporter certificate.

**Severity**: Error (popup)

## 説明

このポップアップ エラーは、ボックス構成が高度なサポーター証明書 (通常のサポーター証明書よりも高い特権セット) を必要とするときに表示されます。有効な高度な証明書が存在してアクティブでない限り、その構成は使用できません。

高度な証明書は、サンドボックスの分離をさらに緩和する機能や、特権プロキシ操作を有効にする機能をゲートするために使用されます。例には、高度な暗号化処理、ネットワーク プロキシ、またはプロジェクトがサポーターのために確保しているその他の機密性の高い機能が含まれます。

## 一般的な原因

- ボックス構成が、高度なサポーター証明書を必要とする機能を有効にしている。
- 高度な証明書がインストールされていないか、インストールされた証明書がアクティブでないか、必要な高度なオプション フラグが欠けている。
- ドライバー/サービスがインストールされた証明書を検出または検証できなかった。

## 推奨される操作

1. メッセージに記載された構成を確認し (%3 は構成識別子です)、証明書を提供する予定がない場合は高度な証明書を必要とする機能を無効にします。
2. 高度な機能が必要な場合は、高度なサポーター証明書を入手してインストールし、それがアクティブであり、必要なオプション フラグを含んでいることを確認します。
3. 証明書のインストール後に Sandboxie コンポーネント (サービスとドライバー) を再起動して、ドライバーが変更を検出できるようにします。
4. 証明書が正しくインストールされていると思うのにメッセージが続く場合は、ドライバー/サービスのトレースを有効にし、トラブルシューティングのためにログを介して証明書照会結果を調べてください。
