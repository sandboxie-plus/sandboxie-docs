# Feature Comparison (obsolete)

Sandboxie Plus と Classic は同じコア コンポーネントを共有していますが、主な違いは Classic UI がもはや開発されていないことです。したがって、新しいコア機能の UI は Sandboxie Plus の SandMan UI でのみ利用できます。同様に、他のさまざまな新機能も SandMan UI でのみ実装されています。もう 1 つの違いは、Sandboxie Plus が[カスタム ライセンス](https://github.com/sandboxie-plus/Sandboxie/blob/master/LICENSE.Plus)の下で提供されるのに対し、Sandboxie Classic は [GPL-3.0+ ライセンス](https://github.com/sandboxie-plus/Sandboxie/blob/master/LICENSE.Classic)の下で提供されることです。

一部の独占機能は、有効な[サポーター証明書](https://sandboxie-plus.com/supporter-certificate/)を持つプロジェクト サポーターのみが利用できます。
<br>Sandboxie Plus を商用または教育の場で使用するには Business Certificate が必要であることに注意してください!
