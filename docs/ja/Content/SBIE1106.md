# SBIE1106

**Message:** SBIE1106 error _[[ntstatus](NtStatusCodes.md) / yy]_, detail _zzz_

**ログ記録先:** [System Event Log](SystemEventLog.md)

**説明:**

Sandboxie のドライバー コンポーネントは初期化を完了できませんでした。このメッセージは、ドライバーが Sandboxie のインストール フォルダーを特定しようとしたときにエラーが発生したことを示します。具体的な問題は、メッセージ内の _yy_ の値によって異なります。

yy = 11 の場合、次のレジストリ キーへのアクセスに問題がありました:
```
	HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\SbieDrv
```

yy = 22 または 33 の場合、上記のレジストリ キーから値 **ImagePath** をクエリする際に問題がありました。

yy = 44 の場合、操作を完了するのに十分なメモリがありませんでした。

yy = 55、66、または 77 の場合、上記のレジストリ キーから **ImagePath** の値で指定されたフォルダーへのアクセスに何らかの問題がありました。

このメッセージの後に [SBIE1103](SBIE1103.md) のメッセージが続きます。
