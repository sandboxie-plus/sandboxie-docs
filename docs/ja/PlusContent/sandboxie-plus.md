[Sandboxie](../Content/Sandboxie.md) は、32 ビットおよび 64 ビットの Windows NT ベース オペレーティング システム向けのサンドボックス ベースの分離ソフトウェアです。オープンソースになって以来 David Xanatos によって開発されており、それ以前は Sophos（Invincea から取得し、Invincea は以前に原作者 Ronen Tzur から取得）によって開発されていました。アプリケーションをローカルまたはマップされたドライブを永続的に変更することなく実行またはインストールできる、サンドボックスのような分離された操作環境を作成します。分離された仮想環境により、信頼できないプログラムと Web サーフィンの制御されたテストが可能になります。

オープンソース化以来、Sandboxie は 2 つのフレーバーでリリースされています。[MFC](https://en.wikipedia.org/wiki/Microsoft_Foundation_Class_Library) ベースの UI を備えた Classic ビルドと、まったく新しい [Qt](https://www.qt.io/) ベースの UI で新機能を組み込んだ Plus ビルドです。新しく追加された機能はすべて Plus ブランチを対象としていますが、多くの場合、[Sandboxie Ini](../Content/SandboxieIni.md) ファイルを手動で編集することで Classic エディションでも利用できます。

Sandboxie の完全なドキュメントは、[サポート ページ インデックス](../Content/AllPages.md)を通じて見つけることができます。または、[ヘルプ トピック](../Content/HelpTopics.md)の概要から直接始めることもできます。
