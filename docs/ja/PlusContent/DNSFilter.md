# DNS フィルター

Sandboxie Plus は、サンドボックス化されたプログラムからの選択されたホスト名ルックアップをブロックまたはリダイレクトできます。ルールは特定のアプリケーションを対象にし、ドメイン パターンを使用できます。リダイレクト ルールは、構成された IPv4 または IPv6 アドレスを返すことができます。

このフィルターは、Sandboxie によって傍受されたサポートされている Windows Winsock サービス ルックアップに対して動作します。ファイアウォールではなく、独自のネットワーク実装を通じて名前を解決するアプリケーション、リモート解決のためにプロキシに名前を送信するアプリケーション、または既知の IP アドレスに直接接続するアプリケーションをカバーしません。

**Sandbox Options > Network Options > DNS Filter** でルールを構成します。構文、アドレス ファミリの動作、プロセスとワイルドカードのマッチング、制限、および別個の **Block DNS, UDP port 53** オプションについては、[ネットワーク DNS フィルタリング](../Content/NetworkDnsFilter.md)を参照してください。

DNS アクティビティのログ記録は別個の診断機能です。その範囲とプライバシーに関する考慮事項については、[`DnsTrace`](../Content/SandboxieTrace.md)を参照してください。
