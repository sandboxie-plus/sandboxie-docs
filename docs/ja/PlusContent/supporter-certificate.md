サポーター証明書はライセンス キーのようなものですが、オープンソース ソフトウェアを使用して支援してくれる素晴らしい人々のためのものです。:-)

Sandboxie を Windows のローリング リリースに合わせて最新の状態に保ち、すべての Web ブラウザーと互換性を保つことは、終わりのない取り組みです。この作業を <a href="https://sandboxie-plus.com/go.php?to=donate">PayPal 寄付</a>または [Sandboxie Plus サポーター証明書](https://sandboxie-plus.com/go.php?to=sbie-get-cert)の購入で支援することを検討してください。[Patreon サブスクリプション](https://sandboxie-plus.com/go.php?to=patreon)で継続的な支援を提供することもできます。

サポート証明書は、[プライバシー モード](../PlusContent/privacy-mode.md)や[アプリ コンパートメント ボックス](../PlusContent/compartment-mode.md)など、新しいサポーター限定機能の使用を可能にします。詳細と証明書のオプションについては、[機能比較表](https://sandboxie-plus.com/feature-comparison/)を参照してください。

**ビジネスまたは教育の場で Sandboxie Plus を使用するには、[Business 証明書](https://xanasoft.com/product/sandboxie-plus-business/)が必要であることに注意してください!**

**Patreon 証明書**は、サブスクリプションがアクティブである限り有効で、すべての機能を解除します。サブスクリプションを終了した Patreon は、支援総額に対応する残存証明書を受け取る資格があります。

**Contributor 証明書**は、プロジェクトに貢献して支援するすべての人が利用できます。これらの証明書は期限切れになりません。あなたがコントリビューターである場合は、電子メールなどで連絡して証明書を取得してください。
