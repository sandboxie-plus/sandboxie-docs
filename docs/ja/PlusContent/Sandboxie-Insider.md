Sandboxie Plus Insider プログラムは、まだ一般には利用できない新機能や機能性への早期アクセスを提供します。

Insider プログラムの参加者になり、新しいリリースを含むプライベート GitHub リポジトリへのアクセスを得るには、ドキュメントの支援、開発、翻訳の提供、または優れたバグ報告の提出など、意味のある方法でプロジェクトに貢献する必要があります。あるいは、Patreon で GREAT ティア以上でプロジェクトを支援することもできます。CONTRIBUTOR または HUGE 証明書を持つすべてのユーザーは自動的に資格があります。

Insider ビルドは、Sandboxie エクスペリエンスを向上させ、システムのセキュリティを強化するために設計されたいくつかの新機能を導入します。

 - [RAM ディスク サポート](../PlusContent/RamDiskSupport.md)は、最新の Insider ビルド以降で利用可能で、ImDisk ドライバーを使用してシステムのメモリ内に仮想ディスクを作成できます。これによりファイル アクセスが高速化し、ディスクがアンマウントされたとき（手動または再起動時に自動的に）にすべてのボックスの内容が破棄されるため、機密性が向上します。

 - [暗号化ボックス イメージ サポート](../PlusContent/BoxEncryption.md)は現在開発中で、機密データをさらに強力に保護するための暗号化されたサンドボックス環境を作成できます。この機能では、ボックスのファイル ルートは AES-XTS 暗号化ボックス イメージからマウントされ、他の暗号も利用可能です。このコア機能への今後の追加には、安全なボックス パスフレーズの処理と、暗号化サンドボックスで実行されていないアプリケーションがサンドボックス化されたファイルにアクセスするのを防ぐドライバー拡張が含まれます。

 - [プロキシ インジェクション](../PlusContent/ProxySupport.md)は、Insider ビルドで追加されたさらに別の機能で、任意のアプリケーションに直接接続の代わりに Socks 5 プロキシを使用させることができます。

 - [DNS クエリのログ記録、フィルタリング、およびリダイレクト](../PlusContent/DNSFilter.md)機能により、サンドボックス化されたプログラムが選択したドメインに対して行う DNS クエリをブロックまたはリダイレクトできます。

 - [USB ドライブのサンドボックス化](../PlusContent/USBSandboxing.md)は、現在のリリースでは有効な適用可能なサポート証明書が必要で、Insider 限定ではありません。適格な USB バッキング ボリュームに対して強制フォルダー ルールを自動的に維持します。

 - Insider ビルドには EFS のサポートが含まれています。これは Windows の機能で、ファイルとフォルダーを暗号化して不正アクセスから保護できます。

 - [ドキュメント ブレイクアウト](../Content/BreakoutDocument.md)は、既知のブレイクアウト メカニズムの拡張であり、開かれたファイル パスに保存された選択したファイル タイプを、関連付けられたアプリケーションのサンドボックス外インスタンスでサンドボックス内から開けるようにします。

次の点に注意してください。

- Sandboxie Plus の Insider ビルドは、バグが多く急ぎすぎた Windows Insider ビルドとは異なります。
- Insider ビルドの新しい点は、新しい機能性と新機能に限定されています。
- 互換性に影響を与える可能性のある実験的なものは、公開 GitHub プレビュー チャネルでテストされます。
- Sandboxie Plus の Insider ビルドは安定した最終リリースに基づいており、その上に新しい機能性が追加されています。
- Insider ビルドは Qt6 でコンパイルされ、統合された x64/ARM64 インストーラーとして提供されます。
