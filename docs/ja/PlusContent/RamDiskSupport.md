# RAM ディスク サンドボックス

## RAM ディスク サポート

Sandboxie Plus は、ImBox と [ImDisk ドライバー](../PlusContent/imdisk.md)を通じて、サンドボックスの内容を RAM バッキングの仮想ディスクに保存できます。RAM バッキングを使用するサンドボックスは 1 つのボリュームを共有し、ボックスごとに別個のディレクトリを持ちます。

## パフォーマンスの増幅

RAM バッキング ストレージは、一部の一時ファイル ワークロードに利益をもたらす場合があります。パフォーマンスはワークロードとシステム メモリの圧力に依存し、永続ストレージより高速な操作を保証するものではありません。

## プライバシーの強化

共有 RAM ディスクにのみ保存された内容は揮発性であり、そのバックエンドが実際に破棄されたときに失われます。サンドボックス化されたプロセスを終了したり、1 つのサンドボックスを閉じたり、SandMan を閉じたりしても、それ自体で共有 RAM ディスクが破棄されたことは確立されません。必要なファイルは事前に永続ストレージに復元またはエクスポートしてください。RAM のみの内容が再起動をまたいで存続すると依存しないでください。

揮発性は、データがページ ファイルやその他の永続ストレージに到達できないことを保証するものではなく、安全な消去の保証でもありません。

## RAM ディスク サポートの統合: ステップ バイ ステップ

前提条件と詳細なストレージ動作については、[RAM ディスクの使用](../Content/UseRamDisk.md)を参照してください。

### サンドボックス構成の更新:

**[Sandboxie Ini](../Content/SandboxieIni.md)** の目的のサンドボックスのセクションに次の行を追加します。

    UseRamDisk=y

### グローバル設定の構成:

**[Sandboxie Ini](../Content/SandboxieIni.md)** の `[GlobalSettings]` セクションで、共有 RAM ディスクの要求容量を設定します。

    RamDiskSizeKb=2097152

この例は 2097152 KiB (2 GiB) を要求します。これは、新しいバックエンドが作成されるときに使用される共有容量を設定します。すべてのサンドボックスの RAM バッキングを自動的に有効にしたり、既存の RAM ディスクのサイズを変更したりするものではありません。作成の制限と変更の適用については、[RAM ディスク サイズ Kb](../Content/RamDiskSizeKb.md) を参照してください。

データ メモリは、バッキングが格納されるにつれて段階的にコミットされます。構成された容量は、その量の物理 RAM の即時予約ではありません。意図したワークロードと利用可能なシステム リソースに応じて選択し、Windows とアプリケーション用の余裕を残してください。システム メモリと共有ボリュームの空き領域の両方を監視してください。物理 RAM の半分を割り当てることが普遍的に安全であるわけではありません。
