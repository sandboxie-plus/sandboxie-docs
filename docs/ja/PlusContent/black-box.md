# ブラック ボックス

**ブラック ボックス**は、選択した基本ボックス タイプを保持しながら 2 つの別個の保護を組み合わせる新しいボックス ウィザードのオプションです。

- [暗号化サンドボックス ストレージ](BoxEncryption.md)。サンドボックス ルートとレジストリ ハイブを暗号化されたディスク イメージに配置します。
- [機密ボックス](../Content/ConfidentialBox.md)。サンドボックス外のホスト プロセスがサンドボックス化されたプロセスとスレッドへのハンドルを取得するのを制限します。

通常の新しいボックス ウィザード ワークフローでは、**Encrypt Box content and set Confidential** を選択すると、基本構成に `UseFileImage=y` と `ConfidentialBox=y` が追加されます。これらの設定は別個のメカニズムのままです。暗号化は主にアンマウントされている間のバッキング ストレージを保護し、機密ボックス フィルタリングはサンドボックス化されたプロセスが実行されている間に作用します。

基本は Standard、[セキュリティ強化](security-mode.md)、または[アプリケーション コンパートメント](compartment-mode.md)で、それぞれ[データ保護](privacy-mode.md)の有無にかかわらず使用できます。作成後、**Box Type Preset:** でこれら 6 つの基本の組み合わせから選択します。暗号化と機密ボックスは独立して構成されます。

SandMan は、基になる基本モードとは独立して、組み合わせた暗号化/機密の表示を表示できます。これは両方の設定で構成された既存のボックスも含みます。ウィザードは依然として選択した基本タイプから枠の色を選択し、本質的にそれを黒に変更するわけではありません。色とアイコンは強制の保証ではありません。[ボックスの表示](../Content/BoxPresentation.md)を参照してください。

マウント ルート保護、[ProtectAdminOnly](../Content/ProtectAdminOnly.md)、`DenyHostAccess` 例外、および [ProtectHostImages](../Content/ProtectHostImages.md) を含む追加の制御には、独自のスコープと既定があります。

ブラック ボックスは、すべての通信またはデータ転送パスがブロックされることを意味しません。通常の Sandboxie のファイル、レジストリ、IPC、ネットワーク、クリップボード、GUI、およびその他のポリシーが、ボックスの実行中に許可される操作を引き続き決定します。
