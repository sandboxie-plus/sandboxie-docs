# 内存盘沙盒

## 内存盘支持

Sandboxie Plus 可以通过 ImBox 和 [ImDisk 驱动程序](../PlusContent/imdisk.md)，将沙盒内容存储在以内存为后端的虚拟磁盘上。使用内存盘的沙盒共享同一个卷，每个沙盒在其中使用独立目录。

## 性能提升

内存盘可能有助于提升某些临时文件操作的性能。实际效果取决于工作负载和系统内存压力，并不保证比持久存储更快。

## 隐私增强

仅保存在共享内存盘中的数据具有易失性，会在该后端实际销毁时丢失。结束沙盒进程、关闭单个沙盒或关闭 SandMan，并不意味着共享内存盘已经销毁。需要保留的文件应提前恢复或导出到持久存储；不能依赖仅存于内存盘中的数据在重启后仍然存在。

易失性不保证数据不会进入分页文件或其他持久存储，也不等同于安全擦除。

## 集成内存盘支持：分步指南

有关前置条件和详细的存储行为，请参阅[使用内存盘](../Content/UseRamDisk.md)。

### 更新沙盒配置：

在 **[Sandboxie Ini](../Content/SandboxieIni.md)** 中，为需要使用内存盘的沙盒添加以下配置：

```ini
    UseRamDisk=y
```

### 配置全局设置：

在 **[Sandboxie Ini](../Content/SandboxieIni.md)** 的 `[GlobalSettings]` 节中，设置共享内存盘的请求容量：

```ini
    RamDiskSizeKb=2097152
```

此示例请求 2097152 KiB（2 GiB）的容量。该值用于新建共享内存盘，并不会自动为所有沙盒启用内存盘，也不会调整已有内存盘的大小。创建限制和更改生效方式见[内存盘大小](../Content/RamDiskSizeKb.md)。

随着数据写入，内存会逐步提交；配置的容量不等于立即预留等量的物理内存。应根据预期工作负载和可用系统资源设置容量，并为 Windows 和应用程序留出余量。同时关注系统内存和共享卷的剩余空间，不能保证分配半数物理内存就一定安全。
