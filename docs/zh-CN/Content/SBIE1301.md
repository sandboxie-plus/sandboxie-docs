# SBIE1301

**消息：** SBIE1301 程序 _program.exe_ 在沙盒外部启动

**记录位置：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

这是一条信息/警告消息。

当一个“程序警报”在 Sandboxie 监管之外启动时，会出现此消息。

当“强制程序”（或来自“强制文件夹”的程序）启动，且“禁用强制程序”模式生效时，也会出现此消息。

有关“程序警报”的配置，请参阅：

*   [配置菜单 -> 程序警报](ConfigureMenu.md#程序警报)
*   [程序设置](ProgramSettings.md#页面-1)

有关“强制程序”的配置，请参阅：

*   [沙盒设置 > 强制程序](ProgramStartSettings.md#强制程序)
*   [沙盒设置 > 强制文件夹](ProgramStartSettings.md#强制文件夹)
*   [程序设置](ProgramSettings.md#页面-1)
