# 外观设置沙盒管理器 > 沙盒设置 > 外观：

![](../Media/AppearanceSettings.png)

通常，Sandboxie 会在与沙盒化程序关联的窗口标题栏中插入 Sandboxie 标记 [#]。

*   可以使用第一个复选框覆盖此默认行为，阻止 Sandboxie 标记出现。

*   可以使用第二个复选框扩展此默认行为，在 [#] 标记之间也插入沙盒名称。当你经常在多个沙盒中使用相同程序时，这很有用。

注意：无法同时启用两个复选框。

如果活动（前台）窗口属于沙盒化程序，Sandboxie 也可以在该窗口周围绘制彩色边框。使用第三个复选框启用此行为，并为此沙盒中的程序选择边框颜色。

相关 [Sandboxie Ini](SandboxieIni.md) 设置项：[标题栏中的沙盒名称](BoxNameTitle.md)、[边框颜色](BorderColor.md)。
