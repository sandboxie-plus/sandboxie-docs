# 便携式沙盒

2.80 版引入的 [沙盒布局](SandboxHierarchy.md) 修订允许沙盒在计算机之间有更强的便携性。通过把程序重定向为创建具有非特定路径的沙盒化对象，可以在一台计算机上填充沙盒，然后把这个沙盒带到另一台计算机上继续使用。

例如，考虑把游戏程序安装到便携式设备（如挂载为 P 盘的 USB 存储棒）上。游戏可能把文件安装到 P 盘上的文件夹中，但它创建的任何菜单快捷方式都会安装到本地计算机的 Windows 开始菜单中，在 P 盘之外。它创建的任何注册表项也会创建在 Windows 注册表中，同样在 USB 设备之外。

相比之下，如果你把 [容器文件夹](SandboxMenu.md#设置容器文件夹) 设置为 P 盘（例如 _P:\Sandbox_），然后把游戏安装到（沙盒化的）C 盘中，那么安装创建的对象_全部_会被重定向到 P 盘。

然后你可以把 USB 驱动器带到另一台安装了 Sandboxie 的计算机上，在那台计算机上也把容器文件夹设置为 P 盘。通过 Sandboxie 开始菜单，你会看到游戏安装的菜单快捷方式；启动游戏时，它会找到记录在沙盒化注册表中的设置。

注意：Sandboxie 本身不是便携软件，但它促进了一大类应用程序的便携性。
