# 即时恢复

![](../Media/ImmediateRecoverFavIcon.png)

即时恢复是 [快速恢复](QuickRecovery.md) 的扩展。快速恢复和即时恢复都会扫描在 [沙盒设置 > 恢复 > 快速恢复](RecoverySettings.md#快速恢复) 中配置的文件夹列表，并提示一种把找到的文件（或文件夹）移出沙盒的简便方式。

快速恢复由显式请求调用，或恰在沙盒被删除前调用——即通常在沙盒化程序运行结束后才调用。相比之下，_即时恢复_在沙盒化程序内部工作，文件一创建并符合恢复条件就会被识别出来。

一旦有文件符合恢复条件，_即时恢复_窗口就会出现；只要窗口保持打开，之后任何符合恢复条件的文件都会被收进该窗口。上方区域（见上图）显示符合恢复条件的文件，下方区域列出目标文件夹。

要恢复文件，先在上方区域选择一个或多个文件，再从下方区域选择一个文件夹，然后点击 _恢复_。（在上方区域用 _CTRL_ 和 _SHIFT_ 键可选择多个文件。）

下方区域最初只提供两个特殊目标：_恢复到相同文件夹_ 和 _恢复到任意文件夹_。它们的作用与 [快速恢复](QuickRecovery.md) 中描述的一致。当你使用 _恢复到任意文件夹_ 命令时，更多目标会被记录到下方区域供日后使用。

*   你可以通过清除 _浏览文件夹_ 对话框（在调用 _恢复到任意文件夹_ 命令时出现）中的 _保存选定文件夹供以后使用_ 复选框来禁用此功能。

_即时恢复_ 可以通过勾选窗口底部的 _在所有沙盒化程序停止前不再提示_ 复选框，临时禁用，直到所有沙盒化活动停止。
