# SBIE1241

**消息：** SBIE1241 无法挂载注册表配置单元：_[xxxxxxxx / yy]_

**记录位置：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

当沙盒化程序启动时，Sandboxie 可能需要为该沙盒准备沙盒化注册表。Sandboxie 会将 [注册表配置单元文件](http://en.wikipedia.org/wiki/Windows_Registry#Hives) 加载到系统中。此错误消息表明发生了问题，并且注册表配置单元文件未被加载。

如果 yy 为 11，则 [注册表根路径](KeyRootPath.md) 设置可能配置不当，导致多个沙盒使用相同的注册表位置（或注册表项）。

如果 yy 为 22，则注册表配置单元文件可能已损坏，或者包含注册表配置单元文件（及其关联沙盒）的驱动器可能已满。

如果 yy 为 33，则 [文件根路径](FileRootPath.md) 设置可能配置不当，导致多个沙盒使用相同的注册表配置单元文件。
