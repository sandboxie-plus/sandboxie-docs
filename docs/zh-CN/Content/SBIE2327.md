# SBIE2327

**消息：** SBIE2327 COM 服务器中出现错误：_[yy / xxxx]_

**记录位置：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

在某些特定情况下，Sandboxie 会代表 Sandboxie 内的程序充当通信通道，并将特定请求转发给在 Sandboxie 外部运行的 COM 对象。

该通信通道由 Sandboxie 服务组件（也称为 _SbieSvc.exe_）启动的 _SbieSvc.exe_ 程序实现。此消息报告在充当通信通道的某个 _SbieSvc.exe_ 程序中发生了错误。

当 Sandboxie 内的程序尝试使用与 [开放 Clsid](OpenClsid.md) 设置匹配的 CLSID 标识符联系 COM 对象时，会使用此通信通道。

相关 [沙盒管理器](SandboxieControl.md) 设置：[沙盒设置 > 资源访问 > COM 访问](ResourceAccessSettings.md#com-访问)

相关 [Sandboxie Ini](SandboxieIni.md) 设置：[开放 Clsid](OpenClsid.md)。
