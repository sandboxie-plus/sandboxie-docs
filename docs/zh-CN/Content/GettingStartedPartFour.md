# 入门指南第四部分

### 第四部分：快速恢复

你可能已经注意到，之前把 _favicon.ico_ 保存到桌面文件夹时，Sandboxie 为该文件提供了 [即时恢复](ImmediateRecovery.md)。但当把 _test1.txt_ 保存到 C 盘根目录时，却没有这样的提示。

这是因为桌面文件夹（默认）被配置为_可恢复_的文件夹位置，你通常希望从中恢复文件。而 C 盘根目录不被视为可恢复位置。

[快速恢复](QuickRecovery.md) 命令会扫描可恢复文件夹，并显示所有可恢复文件的摘要：

![](../Media/QuickRecoverSandbox.png)

你可以调用**快速恢复**命令：

*   通过沙盒管理器主窗口中的 [沙盒菜单](SandboxMenu.md)。

*   右键点击屏幕角落的 [托盘图标菜单](TrayIconMenu.md)。

* * *

上图把 _favicon.ico_ 显示为唯一可恢复文件，因为它是唯一保存到可恢复位置（本例中的桌面文件夹）的文件。

默认设为可恢复文件夹的还有其他位置：_文档_ 文件夹、Windows 的 _收藏夹_ 文件夹。在适用情况下，_下载_ 文件夹也被视为可恢复文件夹。由于这些文件夹中没有任何符合恢复条件的文件，上图完全没有列出它们。

你可以用 _添加文件夹_ 按钮向快速恢复添加更多文件夹。

*   你可以把 [沙盒管理器](SandboxieControl.md) 切换到 [文件和文件夹视图](FilesAndFoldersView.md)，查看并恢复沙盒中任意位置的文件。

* * *

恢复文件（或文件夹）时，你可以选择把文件恢复到沙盒外的对应位置——例如，从沙盒化的桌面文件夹恢复到真实桌面。_恢复到相同文件夹_ 命令（上图中以按钮形式显示）即执行此操作。

另外，你也可以使用 _恢复到任意文件夹_ 命令，把沙盒中的文件移动到计算机系统中的任意文件夹位置。

* * *

### 即时恢复

本指南上一部分简要提到过的 [即时恢复](ImmediateRecovery.md) 功能是 [快速恢复](QuickRecovery.md) 的扩展。即时恢复会持续扫描同一组可恢复文件夹，让你在文件一创建就能恢复：

![](../Media/ImmediateRecoverFavIcon.png)

与快速恢复一样，你可以 _恢复到相同文件夹_ 或 _恢复到任意文件夹_。

* * *

小结：

*   文件必须创建在可恢复文件夹中，才能被 [快速恢复](QuickRecovery.md) 和 [即时恢复](ImmediateRecovery.md) 注意到。

*   你可以自定义可恢复文件夹的集合。

*   你可以用 [文件和文件夹视图](FilesAndFoldersView.md) 恢复不在任何可恢复文件夹中的文件。
