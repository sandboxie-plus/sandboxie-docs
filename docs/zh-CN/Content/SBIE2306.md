# SBIE2306

**消息：** SBIE2306 无法找到用户目录：_[[ntstatus](NtStatusCodes.md) / yy]_

**记录到：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

Sandboxie 试图通过将个人（也称为“用户配置文件”）文件存储在一个通用名称而非特定名称的文件夹中，来增强沙盒的可移植性。

例如，Sandboxie 不会将文件存储在
```
	\sandbox\drive\c\Users\joe\Documents
```

而是更倾向于将文件存储在
```
	\sandbox\drive\c\user\current\Documents
```

这意味着你可以将同一个沙盒与其他用户账户甚至其他计算机一起使用。

此消息表明 Sandboxie 未能找到用户配置文件文件夹，并且不知道要将哪个文件夹与沙盒文件夹 _user\current_ 关联起来。
