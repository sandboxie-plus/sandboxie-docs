# Windows XP 模式

Microsoft 为 Windows 7 提供_Windows XP 模式_，它是与主 Windows 7 操作系统并行运行的 32 位 Windows XP Service Pack 3 的虚拟化安装。

#### Windows XP 模式仅在 Windows 7 的专业版、企业版和旗舰版上可用。

Sandboxie 的 32 位版本可以安装到 64 位 Windows 7 内运行的 32 位 Windows XP 中。得益于_Windows XP 模式_与 Windows 7 环境的无缝集成，32 位 Sandboxie 可以在 64 位 Windows 7 中运行得相当好。

_Windows XP 模式_比运行 Windows XP 的独立虚拟机更易用，因为它更好地集成到 Windows 7 中。它还包含一份授权的 Windows XP 副本。然而，这种改进的集成也使你的 Windows 7 系统和文档暴露于源自_Windows XP 模式_操作系统的恶意更改。

使用 Sandboxie，你可以让网页浏览器隔离在它自己的沙盒中，使其比直接在 Windows 7 上运行的浏览器更安全。

> [Windows XP 模式 - 安装和设置](https://www.sevenforums.com/tutorials/8247-windows-xp-mode-install-setup.html)

一旦_Windows XP 模式_安装到你的 Windows 7 中，以下是在其中安装 Sandboxie 和 Firefox 的分步说明：

*   打开_Windows XP 模式_操作系统。
*   可选：下载并安装 Firefox。确保在安装过程中让 Firefox 把自己指定为默认网页浏览器。可选：也可以调整 Firefox 偏好，并安装你想使用的任何附加组件。
*   下载并安装 Sandboxie。
*   可选：为你的_Windows XP 模式_操作系统下载并安装杀毒软件。
*   从_Windows XP 模式_操作系统注销。
*   在你的 Windows 7 开始菜单中，现在应该能找到 Sandboxie 程序组：_Windows 7 开始菜单 > 所有程序 > Windows Virtual PC > Windows XP 模式应用程序 > Sandboxie_
*   选择 _以沙盒方式运行网页浏览器_，在 Sandboxie 中运行 Firefox。
