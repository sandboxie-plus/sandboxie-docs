# 沙盒管理器

### 概述

沙盒管理器是 Sandboxie 经典版的图形前端，可以控制 Sandboxie 的大部分方面。以下是你可以用它做的事：

*   在 Sandboxie 的监管下启动和停止程序
*   查看沙盒内的文件
*   从沙盒中恢复需要的文件
*   删除沙盒的内容，清除所有不需要的文件
*   创建、移除和配置沙盒

### 可见性

Sandboxie 主要是运行其他程序的机制，而非交互式工具。你通常会隐藏沙盒管理器的主窗口，程序只以系统通知区域（通常在屏幕右下角）中的托盘图标形式可见：

![](../Media/TrayIcon.png)

（注意时钟旁边黄色的沙盒管理器图标。）

要切换隐藏状态，双击托盘图标，或右键点击它并选择 _显示窗口_ 或 _隐藏窗口_ 命令。（参见 [托盘图标菜单](TrayIconMenu.md)。）此外，你也可以点击窗口右上角的关闭按钮（X）来隐藏窗口。

要退出沙盒管理器并从系统通知区域移除其托盘图标，请右键点击托盘图标并选择 _退出_。
