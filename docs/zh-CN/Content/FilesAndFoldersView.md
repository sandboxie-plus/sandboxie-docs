# 文件和文件夹视图

[沙盒管理器](SandboxieControl.md) > [视图菜单](ViewMenu.md) > [文件和文件夹](ViewMenu.md#文件和文件夹)

![](../Media/FileViewFavIcon.png)

_文件和文件夹视图_ 是 [沙盒管理器](SandboxieControl.md) 中的次要视图模式。它显示每个沙盒中的文件和文件夹，组织成文件夹树，并按沙盒名称分组。

每个沙盒内有两个顶层文件夹：

*   _快速恢复文件夹_ 显示配置给 [快速恢复](QuickRecovery.md) 的文件夹，以及这些文件夹内包含的任何文件夹或文件。

*   _所有文件和文件夹_ 以友好的方式包含沙盒的全部内容（如 [沙盒层次结构](SandboxHierarchy.md#文件) 所述）。此文件夹本身又组织为两个文件夹：
    *   _驱动器_ 显示为系统中的驱动器创建的沙盒化内容。
    *   _用户文件_ 显示用户配置文件文件夹的沙盒化内容。用户配置文件文件夹包含如 _我的文档_、_桌面_ 和 _收藏夹_ 等文件夹。
    *   _所有文件和文件夹_ 文件夹通常还包含代表 Windows 注册表沙盒化副本的 _RegHive_ 文件。

使用每个沙盒行开头的 _+_ 或 _-_ 小图标，可以展开或折叠沙盒中文件和文件夹的显示。

**上下文菜单**

_文件和文件夹视图_ 为沙盒和程序提供上下文菜单。要显示某行项目（沙盒、文件或文件夹）的上下文菜单，请执行以下任一操作：

*   在行的任意位置点击鼠标右键。

*   用鼠标或键盘选中（高亮）该行，然后按 Shift+F10。

*   用鼠标或键盘选中（高亮）该行，然后使用 [视图菜单 > 上下文菜单](ViewMenu.md#上下文菜单) 命令。

对于沙盒行，显示的上下文菜单与 [沙盒菜单 > 沙盒子菜单](SandboxMenu.md#沙盒子菜单) 相同。完整说明参见该处。

对于文件或文件夹，上下文菜单提供以下命令：

*   _以沙盒方式运行_ 命令在 Sandboxie 的监管下打开文件或文件夹：
    *   可执行程序文件将被直接调用。
    *   文档文件将在与该文档类型关联的程序的沙盒化实例中打开。
    *   文件夹将在 Windows 资源管理器的沙盒化实例中打开。

*   _恢复到相同文件夹_ 和 _恢复到任意文件夹_ 命令把文件或文件夹移出沙盒。完整说明参见 [快速恢复](QuickRecovery.md)。

*   _将文件夹添加到快速恢复_ 命令在顶层 _所有文件和文件夹_ 文件夹之下的文件夹中可用，将该文件夹添加到 [快速恢复](QuickRecovery.md) 文件夹列表。

*   _从快速恢复中移除文件夹_ 命令在顶层 _快速恢复文件夹_ 文件夹之下的文件夹中可用，将该文件夹从 [快速恢复](QuickRecovery.md) 文件夹列表移除。
