# SBIE2214

**消息：** SBIE2214 启动服务 _name_ 的请求因权限被降而被拒绝

**记录位置：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

沙盒中启用了 [降低权限](RestrictionsSettings.md#放弃权限) 设置，这会阻止服务程序以完全（本地系统）权限启动。

请注意，Sandboxie 的 64 位版本默认启用 [降低权限](RestrictionsSettings.md#放弃权限) 设置。

此消息之后会跟随消息 [SBIE2219](SBIE2219.md)。

**解决方法：** 关闭 [降低权限](RestrictionsSettings.md#放弃权限) 设置。
