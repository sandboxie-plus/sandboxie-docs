# SBIE2211

**消息：** SBIE2211 沙盒化服务启动失败：_名称_

**记录位置：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

安装到沙盒中的 Windows 服务由 Sandboxie 进行管理。此管理包括启动和停止服务。此消息报告沙盒化服务 _名称_ 启动失败。

**用户账户控制**

在 Windows Vista 及更高版本中，除非在运行安装程序之前启用 [以 UAC 管理员身份运行](FileMenu.md#以-uac-管理员身份运行) 选项，否则软件可能无法正确安装到沙盒中。

特别是，通过 Windows Installer 服务安装的 Windows 安装程序包需要启用此选项。这不是安全问题：“以 UAC 管理员身份运行” 选项不会以任何方式削弱 Sandboxie 的保护功能。
