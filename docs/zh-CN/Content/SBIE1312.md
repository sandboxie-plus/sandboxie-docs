# SBIE1312

**消息：** SBIE1312 阻止了在沙盒中启动 16 位 DOS 程序的请求

**记录位置：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

Sandboxie 会阻止在沙盒中执行 16 位 DOS 程序，因为 Sandboxie 无法保证此类程序的沙盒隔离性。

请注意，此消息仅在 32 位 Windows 系统上的 32 位版本的 Sandboxie 中出现，因为 64 位 Windows 系统无法运行 16 位 DOS 程序。

一种可能的解决方法是将 DOS 模拟软件 [DOSBox](https://www.dosbox.com) 安装到沙盒中，并使用它来运行 16 位 DOS 程序。
