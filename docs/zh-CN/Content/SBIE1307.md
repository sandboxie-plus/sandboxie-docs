# SBIE1307

**消息：** SBIE1307 由于限制，程序无法访问互联网 - _program.exe_

**记录到：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

运行该程序的沙盒中启用了互联网访问限制。该程序被禁止访问互联网。

对于任何正在运行的沙盒化程序，此消息仅会发出一次。

相关的 [沙盒管理器](SandboxieControl.md) 设置：[沙盒设置 > 限制设置 > 互联网访问](RestrictionsSettings.md#互联网访问)

相关的 [Sandboxie Ini](SandboxieIni.md) 设置：[封闭文件路径](ClosedFilePath.md)，[通知互联网访问被拒绝](NotifyInternetAccessDenied.md)。
