# 沙盒展示与操作

`BoxIcon`、`CustomColor`、`DblClickAction` 与 `PinToTray` 是 SandMan 的逐沙盒展示与交互设置。它们共用同一个配置面，但用途各不相同：图标展示、切换预设时保留颜色、双击动作、托盘列表过滤。它们都不是沙盒隔离控制项，沙盒的颜色或图标也不能作为其安全预设的证明。

SandMan 当前的读取方直接从沙盒节读取这些值。它们不会请求 `GlobalSettings` 回退、已启用模板的继承或展开后的有效策略查询，也不支持针对这些设置的进程/映像或 ProcessGroup 选择器。仅存在于模板或 `GlobalSettings` 中的值在这里不会被使用。把值复制进沙盒节的工作流会生成一个直接值，这些读取方就能使用；这一限制并不适用于 Sandboxie 配置系统的整体。

当前 Sandboxie Control Classic 代码没有为这四个设置名提供专门的读取方或等效控件。它们出现在 INI 文件中并不会带来相同的 Classic 界面行为。

## 自定义沙盒图标

`BoxIcon` 可以用 `path,index` 形式指定 Windows 图标资源：

```ini
[ExampleBox]
BoxIcon=C:\Windows\System32\shell32.dll,0
```

也可以手动配置绝对图片路径：

```ini
[ExampleBox]
BoxIcon=C:\Icons\box.png
```

直接使用图片时走 Qt 的图片处理，支持的格式取决于该构建中可用的图片支持。`BoxIcon` 会用在 SandMan 的主沙盒列表/树、在沙盒中运行时的沙盒选择器、沙盒选项预览，以及系统托盘的沙盒列表/菜单中，具体受相关图标显示偏好约束。

自定义图标、按颜色生成的图标、沙盒类型图标与状态叠加层是彼此独立的展示层。如果自定义图标无法加载，回退行为会因界面位置而异。托盘在回退到常规的颜色/类型图标之前，会先尝试非内置 `DblClickAction` 的目标图标；主沙盒树不使用同样的回退。图标选择不会改变沙盒类型、安全预设或运行时执行策略。

在 **沙盒选项 > 常规选项 > 沙盒选项 > 外观** 下，打开颜色按钮的菜单并选择 **自定义图标**。图标选择器把 Windows 资源选择结果存为 `path,index`，它不是一个专门的图片路径编辑器。颜色重置控件重置的是颜色，不是 `BoxIcon`。

## 保留自定义颜色

```ini
[ExampleBox]
CustomColor=y
```

`CustomColor` 不定义颜色。实际颜色仍然保存在 [`BorderColor`](BorderColor.md) 中。`CustomColor=y` 告诉 SandMan 在更改 **沙盒类型预设配置** 时保留该颜色。没有这个标志时，更改预设可能套用新选中预设的颜色。即使没有这个标志，自定义的 `BorderColor` 仍然可用；这个标志管的是切换预设时的保留行为。

此设置不会启用边框、不含 RGB 值，也不控制边框宽度或透明度。它同样不会保留旧的安全/隔离预设：即使颜色被保留，更改 **沙盒类型预设配置** 仍会更改适用的预设控件。

没有名为 `CustomColor` 的复选框。**沙盒选项 > 常规选项 > 沙盒选项 > 外观** 下的颜色控件管理它的状态。选择或调整自定义颜色并在应用后，会记录 `CustomColor=y`；重置为预设颜色并在应用后，会移除该标志。没有直接值时，读取方的回退处于禁用状态。

## 双击动作

`DblClickAction` 选择在沙盒上发生适用的双击时执行的动作：

```ini
[ExampleBox]
DblClickAction=!browse
```

在 **沙盒选项 > 常规选项 > 沙盒选项 > 双击动作：** 下，可编辑的选择器提供：

| 值 | SandMan 标签 | 动作 |
| --- | --- | --- |
| `!options` | **打开沙盒选项** | 打开沙盒选项。 |
| `!browse` | **浏览内容** | 打开 SandMan 的沙盒内容浏览器。 |
| `!recovery` | **开始恢复文件** | 打开文件恢复窗口并扫描；它不会启用即时恢复。 |
| `!run` | **显示运行对话框** | 通过 `Start.exe` 打开“在沙盒中运行”对话框。 |

缺少值或值为空时，打开沙盒选项。选择 **打开沙盒选项** 通常会移除 `DblClickAction`，而不是存储 `!options`。以 `!` 开头的未知值同样会打开沙盒选项。**Ctrl + 双击** 无论配置了什么动作都会打开沙盒选项。

非空且不以 `!` 开头的值是命令文本，会被转交给该沙盒的 `Start.exe`，例如：

```ini
[ExampleBox]
DblClickAction="C:\Tools\example.exe" --example
```

这不是 [`RunCommand`](RunCommand.md) 名称、运行菜单标题或程序别名。分派器不会把它与运行菜单条目做解析，当前选择器也不会自动列出这些条目。它不是无限制的 shell 语言解析器；不要假设管道或重定向会被解释。

无效的自定义命令文本仍会导致一次启动尝试，而不是自动回退到沙盒选项。下游可能发生启动错误，且失败时配置值不会被自动删除。在界面中更改动作也可能同时更新自定义图标的选择；应用更改前请先核对。

## 把沙盒固定到托盘

```ini
[ExampleBox]
PinToTray=y
```

`PinToTray` 把沙盒标记为固定，供 SandMan 的托盘列表过滤器使用。没有直接值时，它的读取方与复选框都回退为未固定。它不会为该沙盒额外创建一个通知区域图标。

复选框位于 **沙盒选项 > 常规选项 > 沙盒选项**，标签为 **固定住此沙盒，以便总是在系统托盘列表显示**。勾选会写入直接的 `PinToTray=y`；取消勾选通常会移除该直接标量值。它不会显示继承来的模板/全局值。

SandMan 的偏好项 `Options/SysTrayFilter` 在 **全局设置 > 系统集成 > 任务栏托盘 > 沙盒列表显示：** 下配置。它是管理器偏好，不是由这些沙盒读取方继承的 `GlobalSettings` 值。其缺值回退为 **所有沙盒**。

| 托盘模式 | 非活动且未固定 | 活动但未固定 | 已固定 |
| --- | --- | --- | --- |
| 所有沙盒 | 显示 | 显示 | 显示 |
| 激活或已固定的沙盒 | 隐藏 | 显示 | 显示 |
| 仅已固定的沙盒 | 隐藏 | 隐藏 | 显示 |

上表假定该沙盒本身已启用且可用。固定不会把被禁用或不可用的沙盒强行放进托盘列表；复选框里的“总是”字样不会绕过这些条件。

## 应用更改

在 SandMan 中应用更改，或在外部编辑后重新加载配置。这些设置不需要重启沙盒中的应用程序。

- 更改后的 `BoxIcon` 值会在 SandMan 重新加载/重建相关展示面时出现。已加载的图标会被缓存：仅替换外部图标文件而不更改其配置路径/字符串，可能仍显示旧图标。重启 SandMan 会强制重建其图标缓存。
- 外部更改 `CustomColor` 或其他设置后，请重新打开沙盒选项，以便其控件反映新的直接值。在该界面中切换预设时才会应用颜色保留。
- 每次对适用沙盒双击时都会读取 `DblClickAction`；应用/重新加载配置后的下一次手势即可使用新动作。图标缓存与动作分派相互独立。
- `PinToTray` 在重建托盘列表/菜单时求值。应用/重新加载后重新打开它；固定通常不需要重启 SandMan。
