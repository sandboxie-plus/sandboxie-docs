# SBIE2103

**消息：** SBIE2103 拒绝加载系统驱动程序 _driver_ 的尝试

**记录位置：** [弹出消息日志](PopupMessageLog.md)。

**解释：**

这是一条信息性消息。

在 Sandboxie 监督下运行的程序会被剥夺启动驱动程序所需的权限。~~（除非通过 [阻止驱动程序](BlockDrivers.md) 设置明确允许。）~~

此消息表明沙盒化程序已请求启动驱动程序，并且该请求已被拒绝。

请注意，根据具体情况，此消息*可能*表明尝试将恶意 [rootkit](https://en.wikipedia.org/wiki/Rootkit) 安装到系统中的行为已被 Sandboxie 阻止。另一方面，如果此消息在已知会安装并激活驱动程序的程序的沙盒化安装过程中出现，则上述说法不适用。
