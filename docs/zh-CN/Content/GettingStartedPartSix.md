# 入门指南第六部分

### 第六部分：结语

本教程带你走完了使用和理解 Sandboxie 的基本原理：

```
  * 如何用 Sandboxie 运行你的应用程序
  * 更改如何被拦截在沙盒中
  * 如何从沙盒中恢复重要的文件和文档
  * 如何删除沙盒
```

你可以在 [使用技巧](UsageTips.md) 页面以及特定浏览器的页面中阅读更多关于使用 Sandboxie 的技巧：[Internet Explorer 使用技巧](InternetExplorerTips.md) 和 [Firefox 技巧](FirefoxTips.md)。

使用 Sandboxie 时需要牢记的一个重要点是：它旨在将程序彼此隔离。因此，你应该预期会失去_少量_程序间的互操作性。例如：

* 邮件：点击邮件（_mailto_）链接通常会触发浏览器启动你的邮件软件。除非 Sandboxie 被配置为在该沙盒中运行你的邮件软件，否则这无法正常工作。参见 [常见问题-电子邮件](FAQEmail.md)。

* 你可以避开这个问题：右键点击邮件链接，而不是左键（普通）点击。右键菜单会允许你**复制**邮件地址。然后切换到邮件软件并**粘贴**该地址。如果粘贴的地址以 **mailto:** 前缀开头，务必**删除**此前缀（包括冒号）。

* 下载管理器：点击下载链接会被在浏览器之外运行的软件拦截并处理。当浏览器在沙盒中运行时，这可能导致下载管理器也被启动到沙盒中，而这很可能不是你期望的结果。

* 你可以避开这个问题：右键点击下载链接，而不是左键（普通）点击。右键菜单会允许你**复制**链接。然后切换到你的下载管理器程序并**粘贴**链接，以开始下载。

另一方面，你也不应预期会失去程序间_所有_互操作性。例如，你可能使用一款词典软件，它会对按键或鼠标点击做出反应，在弹出窗口中显示信息。Sandboxie 是否会干扰这一点，取决于该词典软件的设计方式。当事情不如预期时，请在 Sandboxie 支持中报告并寻求解决方案。

* * *

也请花些时间浏览 [沙盒设置](SandboxSettings.md) 窗口中的众多设置。这些设置都有清晰的说明，你会找到许多能在安全与便利之间找到最佳平衡的设置。

例如，有人可能偏好更高的安全性和对网页书签与收藏的控制：先让它们保存进沙盒，再通过 [快速恢复](QuickRecovery.md) 或 [即时恢复](ImmediateRecovery.md) 恢复选定项。（这是 Sandboxie 的默认配置。）

但也有人可能偏好把 Sandboxie 配置成让沙盒化浏览器直接访问书签或收藏，省去中间的恢复步骤，以牺牲一些安全性换取更大的便利。

Sandboxie 让你找到属于自己的安全与便利平衡。

尽情享受！
