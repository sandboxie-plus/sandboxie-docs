# SBIE2205

**Message:** SBIE2205 Service not implemented: _name_

**Logged To:** [Popup Message Log](PopupMessageLog.md).

**Explanation:** Sandboxie uses this general diagnostic when an operation named in the message is not implemented by one of its compatibility components. It is not specific to credentials or [Protected Storage](ProtectedStorage.md). A sandboxed application may continue or fail, depending on whether it needs that operation.

Sandboxie's compatibility implementations do not reproduce every system operation. In the PStore implementation, `IPStore::GetTypeInfo` is one confirmed unsupported method: it logs `SBIE2205` with its name and returns failure. The name displayed in the message identifies what was unsupported. Do not infer from this message alone that credential information escaped the sandbox or that a particular WinCred operation, such as `CredReadA`, is inherently unimplemented.

For related behavior, see [Protected Storage](ProtectedStorage.md), [Open Protected Storage](OpenProtectedStorage.md), and [Open Credentials](OpenCredentials.md).
