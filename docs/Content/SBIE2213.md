# SBIE2213

**Message:** SBIE2213 Windows Credentials cannot be stored in the sandbox

**Logged To:** [Popup Message Log](PopupMessageLog.md).

**Explanation:** Windows Credential APIs let applications store and retrieve user names, passwords, and related sign-in information. Sandboxie's user-mode credential compatibility layer logs this message when it cannot initialize its [Protected Storage](ProtectedStorage.md) (PStore) backing implementation for a credential operation. The initialization path sets `ERROR_NO_SUCH_LOGON_SESSION` and returns failure. An intercepted credential operation that requires that backend can therefore fail; the result depends on the operation. The message does not establish that every credential was discarded.

See [Open Credentials](OpenCredentials.md) for the scope of the WinCred hooks and native read-through behavior, and [Open Protected Storage](OpenProtectedStorage.md) for the separate template that bypasses these compatibility hooks.
