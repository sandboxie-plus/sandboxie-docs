# SBIE2223

**Message:** SBIE2223 To increase the file size limit for copying files, please double-click on this message line

**Logged To:** [Popup Message Log](PopupMessageLog.md).

**Explanation:**

In Sandboxie Control Classic, this message follows a non-hidden [SBIE2102](SBIE2102.md) and offers a quick way to adjust the File Migration size limit. Double-clicking the message opens a confirmation flow that can increase the sandbox's [CopyLimitKb](CopyLimitKb.md). SandMan does not provide the same follow-up shortcut.

The limit is cached in initialized sandboxed processes. Start new affected processes after changing it; this shortcut does not update their existing cached limits.

Related [Sandboxie Control](SandboxieControl.md) setting: [Sandbox Settings > File Migration](FileMigrationSettings.md)

Related [Sandboxie Ini](SandboxieIni.md) setting: [CopyLimitKb](CopyLimitKb.md)
