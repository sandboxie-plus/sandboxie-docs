# Use SbieDesk Hack

`UseSbieDeskHack` remains a supported Sandboxie compatibility setting, but its current behavior is documented together with Sandboxie's Desktop and Window Station architecture.

[See Sandbox Desktop and Window Station](SandboxDesktop.md).

The setting is enabled by default and can also be configured for individual executable images:

```ini
UseSbieDeskHack=n
UseSbieDeskHack=program.exe,n
```
