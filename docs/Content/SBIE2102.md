# SBIE2102

**Message:** SBIE2102 File is too large to copy into sandbox - _path_

**Logged To:** [Popup Message Log](PopupMessageLog.md).

**Explanation:**

This is an informational message.

When an operation needs to change an existing host file through normal file migration, Sandboxie first needs a sandbox copy so that the host file remains unchanged.

Copying a small file is generally less costly than copying a large one. Migrating large files can take noticeable time and consume additional sandbox storage.

For example, modifying a 4 GB DVD backup through content migration can require copying that large file into the sandbox. Ordinary read-only access normally does not require such a copy. The time and storage cost of migration depend on the file and storage environment.

SBIE2102 is the fallback notification when the normal content-migration size decision reaches or exceeds a finite [CopyLimitKb](CopyLimitKb.md) threshold, no explicit migration rule has already selected another mode, and no usable migration-prompt reply is returned. It is issued only when [CopyLimitSilent](CopyLimitSilent.md) is not enabled. This can occur with prompting disabled or with an unavailable or timed-out interactive request.

A matching explicit migration rule bypasses this size-message path. An affirmative [large-file prompt](PromptForFileMigration.md) reply selects migration; an explicit **No** reply selects non-copy without SBIE2102 from this decision path. _CopyLimitSilent=y_ suppresses SBIE2102 but does not change the migration decision or disable the prompt.

For an initial migration-dependent open that is not approved, [CopyBlockDenyWrite](CopyBlockDenyWrite.md) controls access denied versus a retry against the host file after removing write and delete access. The retry can fail; the message does not guarantee that the file becomes readable or read-only. Selecting migration also does not guarantee that copying succeeds.

The size threshold and alert message can be configured in [Sandbox Settings > File Migration](FileMigrationSettings.md).

Related [Sandboxie Ini](SandboxieIni.md) settings: [CopyLimitKb](CopyLimitKb.md), [CopyLimitSilent](CopyLimitSilent.md), [PromptForFileMigration](PromptForFileMigration.md), [CopyBlockDenyWrite](CopyBlockDenyWrite.md)
